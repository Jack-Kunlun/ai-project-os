## 项目是什么、现在到哪一步

AI Project OS 是可自行部署的个人与团队知识、项目工作台，核心流程是“收集资料 → 整理并核对事实 → 带引用提问/调查 → 人工纳入项目计划 → 跟踪进展”。普通用户维护知识和项目，项目成员按权限协作，平台管理员维护账号、模型、额度与运行配置。

项目已经形成应用和多轮版本交付，不处于从零立项阶段。当前源码包含知识、项目计划、资料整理、统一问答、图谱/检索、受控连接、模型管理和双端界面；v1.2.25 有历史发布与代理安装回执。全系统 UI 整改和实际页面验收已完成，历史范围见[验收报告](UI-REMEDIATION-20261115.md)。本次发布接收了 17 项缺陷修复和模型设置调整，其他待办及文档校对见[任务台账](TASKS.md)。

以下表格保留 2026-11-02 历史快照。随后的验收记录涵盖 11 月 15 日全系统 UI 整改、11 月 20 日上线和 11 月 23 日缺陷修复。
