## 安全与数据边界

本地注册不收邮箱，账号不具有已验证邮箱身份，也不能由该入口取得已验证身份赠额。新账号应仅为平台普通用户，在自己的个人工作区为 Owner；这不意味着平台管理员权限。邮箱邀请和邮件找回密码仍不属于该入口能力。

唯一测试账号 `registration-acceptance-20261006` 已于 2026-10-06 09:42（Asia/Shanghai）创建；预检时该用户名尚未占用。密码由用户直接在浏览器输入并提交，没有读取或保存到聊天、源码、日志或验收材料。测试账号未创建项目、上传文件或接入模型、仓库、MCP；账号和空个人工作区仍保留，尚未停用或删除。最后的验收会话已经退出，并验证受保护的个人资料页返回登录页。
