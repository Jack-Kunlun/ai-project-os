# v1.2.14 — 补齐折叠卡片的底部留白

计划页的全部目标、带证据的智能体建议、计划健康与仓库变更、最近计划审计，以及概览页的运行与治理区，展开后由外层容器统一保留与左右一致的底部留白。最后一张内层卡片不再贴住外层底边，目标与审计列表原有的底部间距不会重复叠加。

收起后的卡片保持紧凑高度。回归检查覆盖中文浅色桌面、英文深色 390px 窄屏、空列表与有目标/审计记录、展开间距、收起高度和横向溢出。业务逻辑、权限、接口、依赖及迁移清单不变，仍为 150 条迁移。

正式 CI 按累计差异运行受影响的 unit 合同和浏览器用例，并保留静态、构建和性能预算；正式发布复用同 SHA 的不可变镜像。线上结果以发布回执及公网健康检查为准。
