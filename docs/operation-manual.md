## 当前边界速览

- 普通用户通过 Dashboard 和项目内六个一级入口工作：项目概览、项目计划、项目资料、AI 工作台、项目自动化、项目管理；任务和资料详情等必要子页从对应入口进入。
- 平台默认模型由平台管理员在 `/admin/models` 维护，默认能力路由、额度和探测预算分别在 `/admin/models/routes`、`/admin/credits` 和 `/admin/operations/probes` 管理。
- 普通用户不能进入管理员页面或配置平台模型和会员资格，但可在个人中心维护只属于自己的 Git/MCP 连接；管理员不代持个人连接凭据。普通用户使用平台额度，有效会员才可配置个人模型，且个人模型须经连接所有者与项目 Owner 双确认委托后按项目使用，不会自动替代平台默认模型。
- 账号停用、恢复和用户安全摘要归 `/admin/users` 用户详情页；停用账号仍可审计但有效结果为 `effective=false`，平台管理员不隐含工作区或项目 Owner 权限。
- MCP 个人连接与工具发现、管理员净化快照审核、项目连接委托和只读工具授权控制面已开放；远端动作调用、调用审批、派发和结果查看/导入仍冻结，不能通过内部 API 绕过。
- 模型外发以页面当次确认范围为准：所有待生成片段会发送给供应商；复用片段不会再次外发。
- 项目内容、凭据和数据库属于不同安全边界。不要把 Token、密码或私钥写入项目资料、日志、URL 或文档。
- 备份恢复需要 PostgreSQL、主密钥和上传文件的组合；不要删除持久化卷。

如需升级、备份或恢复，请由具备对应权限的管理员按管理员指南执行，并在真实运行环境单独记录验证结果。
