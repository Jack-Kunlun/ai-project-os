# v1.2.0 — 全站界面、主题语言与跨页问答

按确认原型统一用户侧和管理端的导航、页面、弹窗及抽屉，保持现有真实接口、权限和外发确认流程。

## 页面与使用体验

- 用户侧与管理端共用中文/英文和浅色/深色/跟随系统设置；登录、注册、找回密码及公共信息页面保持一致。资料正文、问题、回答、引用和用户自定义名称保留原文。
- 项目概览位于项目菜单首项，当前工作空间和项目均可切换；账户、帮助、通知和外观入口集中在头部，知识图谱保留独立入口。
- 统一表单留白、边框、标题、主操作、悬停及深色对比度，改善窄屏导航。弹窗和抽屉支持安全的空白处关闭及键盘焦点返回，有未保存内容时保留既有确认边界。
- 智能问答保留独立页面，并支持其他页面的悬浮使用；详情操作层打开时调整问答入口位置，避免遮挡。

## 会话与用量

- 会话可置顶和重命名，重新打开后可继续追问；同一会话内切换本轮范围，每轮保留当时的范围、模型与引用快照。
- 会话展示修改采用独立的追加式修订，不覆盖原始问答及不可变证据。并发修订冲突明确提示；账号和项目权限变化后重新检查可见性。
- 会话、每轮问答及识别、简报、调查、自动化任务的可审计 Token 记录在相关详情和用量页统一查看。Token 与平台额度分别展示，缺失或未知消耗不当作零。
- 跨页请求与外发确认共用请求锁；保留逐次确认、幂等执行和账号切换后的旧响应隔离。
