# 项目记录模板

本页提供可复制的最小模板。任务状态只写入[任务总台账](TASKS.md)，范围决策只写入[变更日志](CHANGES.md)。证据索引集中存储候选、检查与回执的位置；模板中的路径或链接须指向实际存在的内容。

## 任务

```text
ID：T-___
标题：
来源/关联：原话或实际链接、记录日期、需求 ___ / 变更 C-___ / 问题 T-___
父任务 / 关联处理任务：T-___；不适用则说明
事件记录：ACTIVITY 中 A-___，或既有任务内的可定位记录
类型：需求 / 调查 / 设计 / 实现 / 测试 / 文档 / 问题报告 / 缺陷 / 发布 / 运维 / 管理
状态：待澄清 / 待开始 / 进行中 / 待验收 / 已验收 / 已取消
优先级：P0 / P1 / P2 / P3
里程碑/目标版本：
执行者 / 验收者：
工作区/分支/SHA：
模块归属：主责 F-___；受影响 F-___；不适用说明
交付者 / 接收者：实际承担者；同人承担需分别记录
交接合同：来源/目标、接口或服务版本、输入输出/状态权威、消费者、失败归属；详见交接记录
命中复发记录：L-___；适用组件/页面/状态；排除理由（如有）
目标及验收条件：
范围 / 非目标：
依赖：
阻塞原因 / 解除条件：无；或说明
暂停点 / 恢复后第一步：不适用；或说明
产物：文件/原型/检查记录；已授权提交后再填 commit/PR，未提交写明
当前已完成：
当前剩余 / 下一步：
验证：命令或操作、结果、候选身份
证据链接：
未验证项/风险：无；或说明

```

## 发布记录

```text
版本：
候选分支/生产源/候选 SHA：
不可变镜像摘要/清单：
适用累计风险及 CI 运行链接：
已验收里程碑/未关闭任务：
发布范围内缺陷：
迁移清单是否变化及升级证据：
发布 Workflow 与回执：
上线检查：app / Worker / 数据库账本 / 目标健康
现场核心流程/外部服务结果：逐项记录；未执行写未验证
异常、恢复或后续任务：T-___
状态：待发布 / 发布中 / 已发布待观察 / 已观察 / 发布失败
```

不要凭空填日期、负责人、工期、百分比、测试通过、缺陷根因或线上状态。实际值未知时用“待补/待核实”；状态以台账和证据更新为准。

## 模块或阶段交接

```text
关联 T / C / R：
源模块/阶段 → 目标模块/阶段：F-___ → F-___；或阶段名称
实际交付者 / 接收者 / 验收者：
交付目标及非目标：
合同版本：PRD/设计、现有接口/服务/Schema/组件契约的真实位置与版本
输入及前置：actor/权限、资源范围、状态、配置、依赖；不记录秘密
输出及数据/状态权威：字段/单位/空值/错误/分页等适用约定；引用权威来源
异步或副作用：运行 ID、成功/失败/未知、幂等/取消/重试/对账责任；不适用说明
安全边界：权限复核、来源/外发确认、额度、敏感数据；按实际风险填写
受影响消费者 / 兼容方案 / 变更 C：
产物身份：实际文件、设计版本、基准 SHA + 未提交文件哈希，或已提交候选
验证：正向、错误、边界与集成场景 → 实际用例/审阅 → E 证据
未验证 / 遗留问题 T / 阻塞及解除条件：
接收结论：接受 / 拒收 / 待核实；实际日期、操作者、范围和理由
失败处理 / 回退责任 / 恢复后第一步：
交接暴露问题的改进：问题 T / 命中 L、合同差异 C、受影响消费者和重新验证 E；未变合同直接引用
执行事件 A：保留首次失败、变更和复验；状态仍在 TASKS
```

小任务可把适用字段合并入任务卡，未变化合同直接引用；不要为无关内容制造空模板。接收范围只能由实际证据支持，文档交接不等于运行验收。
