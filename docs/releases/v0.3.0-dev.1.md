# v0.3.0-dev.1

状态：`CONTROLLED_PRERELEASE`

v0.3.0-dev.1 是当前唯一受控生产预发布版本，仍不是稳定版或 GitHub Latest。旧 `v0.2.0-dev.1` 与其他 dev tag 不得进入生产入口。

## 本版本范围

- 平台管理员与普通用户使用完全分开的工作台；管理员只负责平台配置、用户运营、安全审计和受限运维。
- 平台模型、默认路由、平台额度、连接探测预算和用户运营拆分为独立管理入口。
- 管理员 Git、旧会员和旧账号矩阵入口退出正常导航，遗留 URL 由服务端守卫后跳转。
- 普通用户模型、平台默认模型、连接测试失败状态和配置交互按当前权限边界展示。

## 升级边界

生产源版本为 `0.2.0-dev.1`，预检要求 `_prisma_migrations` 精确匹配前 102 个迁移的名称、SHA-256、完成状态和应用步数，并在停写窗口完成第 103 个迁移 `20260917010000_add_platform_bootstrap`。预检继续拒绝不完整或错误账本、schema 不符、clean-slate 遗留数据和活跃客户端。

部署仍必须先完成标签 CI、加密异地备份、停写预检、迁移、健康和恢复边界检查；正常流程不执行清库、drop、truncate、down -v 或卷擦除。
