# v1.2.8 — 可拖动问答浮窗与统一操作按钮

在业务弹窗或抽屉中打开智能问答后，原表单保持可操作。问答使用非模态浮窗，桌面优先放在表单旁；标题栏与收起后的入口都支持拖动，方向键移动、Shift 小步微调，窗口限制在可用视口内。窄屏使用较矮窗口，保留原表单底部操作。收起、重新打开及业务窗口切换保留问答和问题草稿；在问答内按 Esc 只收起问答。

新建项目、添加本地成员和团队、项目成员邀请等基础表单隐藏问答入口，快捷键不会绕过该设置。关闭基础表单后恢复全局入口。完整问答页与原有停靠继续使用同一会话。

业务操作按钮采用共享的 40px 高度、12px 字号、左右 16px 内边距与 8px 图文间距。图标按钮、行内链接、页签和认证表单保留各自控件规格。中英文与明暗主题使用相同尺寸规则，兼容入口复用实际页面组件。

不新增依赖、API、权限、数据结构或数据库迁移，迁移清单保持 150 条。原有模型发送确认、计费、审批与请求保护不变；隔离浏览器中的样本不代表真实模型或第三方服务验收。

浮窗交互增加少量客户端代码。静态资源 gzip 总量预算由 868 KiB 调整至 870 KiB，关键页面、共享脚本、最大文件和 CSS 预算保持不变。

代码和本地检查不代表生产已切换。发布以精确提交 CI、不可变镜像、部署回执及公网健康检查为准。
