# v1.2.11 — 精简新建项目弹窗

新建项目按已确认原型只展示项目名称、可选描述和简短的目标工作区提示（名称保留原文）。移除英文副标题、项目隔离长说明和重复的工作区提示框，缩短窄屏表单；字段占位文案也与原型保持一致。

工作区提示在宽屏与操作同行，窄屏在操作上方。取消与创建按钮保持 40px 高度及 16px 间距，关闭按钮保持 32px；基础表单继续隐藏智能问答入口。提交、权限、工作区选择、焦点管理及错误保留草稿的行为不变。

验证覆盖中文宽屏、英文深色 320px/390px 与 568px 短屏，以及 `/projects?create=1` 兼容入口。发布使用精确主分支 SHA 的成功 CI 与不可变镜像；生产状态以部署回执和公网 `/api/health` 为准。本地不启动 Docker。

无新增依赖、接口或数据库迁移，迁移清单仍为 150 条；沿用静态客户端 gzip 总量预算 892,160 bytes，其他性能阈值不变。
