# v0.7.18 — 浏览器任务取消安全修复与验收收口

## 更新内容

- 修复浏览器 broker 在执行器清理失败后仍可能确认取消成功的问题。只有确认清理成功的任务终态允许确认取消；清理失败或未知执行器错误返回失败，并锁定 broker 为不可用，拒绝排队和新请求，直到运维验证清理并重新启动。
- 增加实际应用服务、TLS/HMAC broker、Chromium、合成 HTTPS 站点与 PostgreSQL 的组合验收，覆盖 JavaScript 审核发布、站点登录 Owner 私有预览、运行中取消、资源清理与迟到结果阻断。
- 收录 [Git 生产收尾验收](v0.7.17-git-acceptance.md) 与 [S1b 本地受控验收](v0.7.17-s1b-local-acceptance.md)。Git 首轮自动读取和元数据发布通过；S1b 本地检查共 50 项通过、0 跳过，独立审查无剩余阻塞。

## 能力边界

S1b 的真实生产宿主隔离、固定镜像 RepoDigest、生产 one-shot CLI、真实授权站点与崩溃恢复尚未验收。本补丁不部署独立 broker、不启用生产网页浏览器开关，不将本地测试专用适配器用于生产。站点登录结果始终仅 Owner 私有预览或丢弃，不进入项目通用资料、搜索、AI 或 MCP。

OIDC 按用户决定暂缓；模拟 MCP 客户端结果不等于独立第三方客户端互操作。Git 本轮未制造新提交，不扩大为变化后自动代码发布已完成现场验收。
