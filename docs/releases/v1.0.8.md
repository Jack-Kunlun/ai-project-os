# v1.0.8 — 兼容 Docker 镜像存储身份

修复正式发布在 Docker 29 containerd 镜像存储下误判目标镜像的问题。CI 发布清单保存注册表的规范配置摘要，生产继续校验不可变注册表摘要、版本、提交、来源和平台，并按 Docker 实际返回的镜像身份固定服务、验收和记录回执。兼容传统存储的配置摘要和 containerd 存储的清单摘要，不放宽为可变标签。

CI 在发布镜像后、上传发布清单前，从注册表拉回相同摘要镜像，与已验证镜像比较文件系统与运行配置，再创建不启动的临时容器核对运行身份并精确删除。此检查不重新构建、不启动业务应用或修改生产。

`v1.0.7` 因镜像身份检查失败而未上线；失败发生在停止服务和迁移之前，发布器已恢复源版本，线上仍为 1.0.5。该次未执行旧镜像或缓存清理，已拉取的应用镜像会占用少量额外空间。不可变的 1.0.6、1.0.7 标签保留。

本版本继承 CI 镜像复用、风险分层、手动正式发布和验收后清理策略。无新增数据库迁移；实际版本、健康与释放空间以本次生产回执为准。
