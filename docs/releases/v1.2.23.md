# v1.2.23 — OpenAI 专用代理接入

支持通过服务端环境变量 `AI_PROJECT_OS_OPENAI_PROXY_URL`，为固定官方地址的 OpenAI 生成、向量和视觉请求配置 HTTP CONNECT 代理。配置为空时保持直连；其他供应商和业务网络请求不使用此代理。不修改官方 API 地址、不启用全局代理、不关闭 TLS 证书验证。代理配置无效或代理不可用时明确失败，不自动回退直连或重试模型请求。

应用和自动化 Worker 从现有部署环境读取同一配置。生产安装器使用独立的受限服务运行 Mihomo，仅在 Docker 网桥地址监听，并只放行 `api.openai.com`；提供安装检查和回滚步骤。实际启用需要完成受控的管理员安装及现场验收，发布应用代码本身不代表代理已启用。

本次没有数据库迁移，不调整模型凭据、测试额度或项目资料外发授权。源码与发布镜像检查以本版本精确提交的主分支 CI 为准；真实 OpenAI 密钥和模型调用需单独验证。
