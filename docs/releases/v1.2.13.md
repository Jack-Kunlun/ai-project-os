# v1.2.13 — 按受影响范围运行 CI

CI 根据当前生产源提交到候选 SHA 的累计差异、TypeScript 反向依赖和显式路由覆盖，选择相关的 unit 合同与浏览器用例。共享用户侧栏执行布局、滚动及真实项目切换三个聚焦 spec；纯 UI 不重复无关服务端覆盖率、数据库业务门禁与 Compose 候选。Lint、类型、生产构建和性能预算继续保留。

源码与镜像作业独立计算检查计划，核对指纹并保存执行回执。空选集、缺失用例、全部跳过、执行失败或身份漂移不能通过。敏感及未注册的浏览器测试按高风险处理；全局布局、选测策略、运行器、共享夹具和无法证明覆盖的改动回退完整验证。

发布继续复用精确主分支 CI 的同一份不可变镜像，不重复编译或在标签阶段重跑测试。本次调整涉及 CI/CD，自身仍执行完整浏览器与同镜像候选验证；后续 UI 发布使用新的选集规则。没有新增依赖、接口或数据库迁移，迁移清单仍为 150 条。正式上线结果以发布回执与公网健康为准。
