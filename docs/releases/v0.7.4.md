# v0.7.4：手机号认证、短信配置与账号注销

本版本包含注册页布局调整、手机号认证、三种短信供应商配置、发送前图形验证码和账号注销，同时提交 v0.7.3 的生产功能验收、注册验收与发布记录修正。源码版本、GitHub Release 与实际生产运行分别核对；部署结果以公网 `/api/health`、受保护的 `last-deployment` 和数据库迁移账本为准。

## 新增能力

- 中国大陆 +86 手机号注册及验证码登录；手机号也可作为密码登录的用户名。验证通过后，未注册手机号在本地注册开放时创建普通账号与独立个人工作区。
- 后台「配置中心 → 短信服务」支持阿里云个人短信认证 PNVS、阿里云企业标准短信 SendSms、腾讯云 SendSms。必须先发送、验证真实测试短信，再保存启用；密钥加密保存，不回显。
- 每次用户或后台测试发送短信前，先完成图形验证码。验证码绑定浏览器、手机号、用途和当前访问版本，一次消费；短信发送和猜测使用持久化预算及反重放约束。
- 个人中心账号注销须再次验证身份并明确确认；注销撤销会话和授权。手机号可重新注册全新账号，不恢复旧资料。
- 注册卡片拓宽；创建账号与 GitHub 按钮居中、最大宽度 320px。桌面常用尺寸减少纵向滚动；小屏保留必要的纵向浏览。

完整配置与限制见[手机号认证说明](../phone-authentication.md)。不包含旧账号手机号绑定/换绑、国际号码或密码找回。

## 验收和发布门槛

本地认证回归 58 项、供应商协议 12 项、独立 PostgreSQL 140 条迁移与 37 项行为检查通过；完整 PostgreSQL 18 OID10 权限门禁通过。三供应商及图形验证码分别完成独立安全审查。真实供应商送达尚无凭据与号码现场证据，测试网络替身不能证明真实服务可用。

稳定发布默认取得同 SHA 的成功 `main` CI 和新带注释标签 CI，包含完整数据库、浏览器和隔离 Compose 作业。用户明确决定 0.7.x 按开发版本快速发布，本次复用已完成的新功能、完整 140 条迁移、权限、构建和安全审查证据，不以旧数据兼容或重复完整 CI 作为发布门槛；未通过的完整 CI 不宣称通过。此前第 4、5 项的结果详见[生产功能验收](v0.7.3-production-acceptance.md)、[注册验收](v0.7.3-registration-acceptance.md)和[发布记录修正](v0.7.3.md)。

## 当前生产的精确升级入口

源版本固定为 `0.7.3`，历史部署 revision 为 `9f4b34b746d9433e51fbf0c2e00d375fa841aac0`，目标账本为 140 条。旧标签已删除且不重建；历史 `Deploy application` 和 `Deploy v0.7 with database migration` 不适用于本次升级。

使用新增的 `deploy/production/ai-project-os-v074-deploy.py`，由现有运维账户 `deploy` 人工将已审查、哈希核对的文件安装为 root 所有、0700 的受保护工具，再通过 sudo 执行。入口校验生产来源记录、现有三种 writer 镜像/容器身份、公网及本机健康、前 135 条迁移名称与 SHA-256，以及目标带注释标签与精确 SHA。预构建后再次核对来源；停止 app/worker/git-worker 并确认数据库无其他客户端，才执行新增迁移、principal reconcile 和 140 条账本核对，随后启动新 writer。

遵照用户明确决定，本次不执行备份/恢复或额外演练、不增加云主机。快速发布命令须显式确认 `CONFIRM_V074_FAST_WITHOUT_BACKUP_OR_LEGACY_ACCEPTANCE`，在部署记录保留 `ci_acceptance=waived_by_user_pre_1_0`；原 `CONFIRM_V074_WITHOUT_BACKUP` 入口继续要求双 CI。数据库迁移开始后若失败，保持 writer 停止并报告需运维处理；不启动旧代码。本入口只支持本次精确升级，不是任意版本部署接口。

## 部署开关与未验收边界

首次部署保持 `PHONE_AUTH_ENABLED=false`，保留原有用户名密码注册。脚本在主机受保护配置内生成缺失的 `PHONE_AUTH_SECRET`，以便管理员完成供应商真实测试；不输出密钥。收到验证码并通过后台测试后，管理员可保存供应商配置，随后按部署配置流程启用手机号总开关。仅在后台启用供应商不自动改变主机总开关。

继续沿用单云主机约束，未启用 S1b 的专用 Linux broker、真实站点及其他外部服务验收；这些范围的既有发布豁免不构成互操作通过证据。

## 新页面性能预算

完整生产构建测得全部静态资源 gzip 合计约 770 KiB，超过旧的 760 KiB 聚合预算；它包含所有页面，不等同于一次页面加载。新增短信管理、验证码及认证界面后，将聚合上限调整为 780 KiB，同时新增登录、注册（各 155 KiB）及短信管理（160 KiB）逐页门禁。实测约 147.6、141.3、154.7 KiB；原共享 JavaScript、最大单资源、全局 CSS 和八个关键页面上限保持原值。

历史 AI/RBAC 数据库夹具调用当前授权服务时，补齐仅表示未注销工作区的 `Workspace.closedAt` 空值列，保留历史迁移账本；独立 Linux PostgreSQL 实际策略门禁复跑通过。
