# AI Project OS v0.2.0-dev.1

`v0.2.0-dev.1` 是受控预发布，不是稳定版，也不应标记为 GitHub Latest。

本版本完成 0.2.x 产品模型重塑：账号与会员权限、个人 AI Provider、平台默认模型路由、Git/MCP 私有所有权、系统管理与有效访问审计均以当前产品语义重新收口；已删除的 workspace-scoped AI Provider、遗留 `ProjectAiRoute` 和旧工作区 BYOK 不再恢复。

数据库从线上错误运行版本 `5.1.2` 升级时，部署器要求旧库恰好包含前 50 个已知迁移及对应校验和，并在只读事务中验证旧 Schema 和 clean-slate 阻塞数据。候选镜像在旧服务仍健康时预构建；备份通过后精确停止旧 app/worker，再以新快照确认同库客户端清空。第 51 至 102 个迁移中的 clean-slate 破坏性 DDL 会先安装数据库写入栅栏，检查前已存在的阻塞数据和检查后的遗留写入都会失败关闭。迁移开始前失败会恢复精确旧容器；一旦数据库变更开始，系统不会自动启动旧版本。

生产工作流只精确接受 annotated tag `v0.2.0-dev.1`，并要求该标签的精确提交已通过标签 push CI、版本与 `package.json` 一致、受限 SSH gateway 已升级、异地加密备份可恢复且生产 Environment 配置完整。其他预发布标签继续失败关闭。

真实第三方模型、Git、OIDC 和 MCP 凭据仍必须在目标部署上分别现场验收；本地或隔离服务不能替代这些结果。
