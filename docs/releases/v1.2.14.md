# v1.2.14 — 统一弹窗表单与卡片留白

操作弹窗复用公共标题和内容区，清理团队成员、邀请、OIDC、外部来源、仓库范围、自动读取提案、项目状态与动作等表单中残留的旧页面标题、背景、边框和重复内边距。Git/MCP 连接表单保留既有固定操作区，直接使用弹窗标题，移除原先靠 CSS 隐藏内层标题的兼容规则。

短表单采用紧凑弹窗，内容填满可用宽度，主操作与取消使用统一的紧凑按钮组。手动事实编辑采用中性表单样式，保留资料原文预览；凭据、授权、外发、审核和证据分组继续保留。

计划页的全部目标、带证据的智能体建议、计划健康与仓库变更、最近计划审计，以及概览页的运行与治理区，展开后由外层容器统一保留与左右一致的底部留白。最后一张内层卡片不再贴住外层底边，目标与审计列表原有的底部间距不会重复叠加；收起后保持紧凑高度。

正式发布前须通过全系统页面矩阵和聚焦弹窗回归，验证桌面/窄屏、中英文/明暗主题、空/有内容、表单草稿、展开留白、收起高度与横向溢出。业务逻辑、权限、接口、依赖及迁移清单不变，仍为 150 条迁移。正式发布复用同 SHA 的不可变镜像，线上结果以发布回执及公网健康检查为准。
