# v1.2.2 — 统一交互与会话体验

本次版本将确认原型中的导航、图标、会话与知识点查看改动落实到正式代码。

## 使用变化

- 全局使用静态 Tabler 图标，统一线宽、尺寸、按钮和文字对齐。工作台卡片的查看入口位于右上角；主内容留白以项目计划为基准。
- 子页面返回明确的父级，弹窗和抽屉统一以关闭图标退出。窄屏导航支持点击外部关闭、Escape 和焦点返回。
- 智能问答默认展示最近会话，收起后保留最小侧栏；新建、置顶、重命名、归档、移至回收站和恢复在侧栏完成。归档与回收站是显示状态，原始问答和引用仍保留。
- 输入框持续展示模型供应商、范围与计量条款；点击发送或按 Enter 授权本轮请求，Shift + Enter 换行，不再打开二次确认弹窗。模型或计量条款变化时停止发送并提示重新核对；服务端继续逐次校验权限、输入指纹、来源快照、有效期及调用审计，不自动重试结果未知的调用。
- 知识图谱点击节点打开当前知识点详情，来源正文独立查看；移除重复的通用问答页头入口，保留跨页面悬浮问答。
- 通知支持全部标记已读，覆盖分页以外的可见消息；新到达消息及待处理事项状态不受影响。
- 补齐系统英文文案；资料正文、用户标题、问答与引用保留原文。

## 数据与发布边界

新增一条仅包含默认 false 的 archived/deleted 展示字段迁移，总计 150 条。原有迁移 SQL 不修改；会话展示修订继续追加写入并使用修订号处理旧窗口冲突，原始会话、问答、来源快照及用量不覆盖或删除。

发布前运行聚焦行为检查、项目规定的静态检查、单元与覆盖率、PostgreSQL、账号认证、OID10、浏览器及同镜像候选验证，并进行独立审查。实际通过记录以精确提交的 CI 产物为准；生产运行以发布回执和公网健康为准。本地和 CI 使用隔离数据及模型交互 fixture，不代表真实模型、短信、Git、OIDC 或第三方 MCP 现场联调。

常规发布沿用通过精确主分支 CI 的不可变镜像，不在生产构建；不创建或验证备份、不执行恢复演练，保留业务数据、上传文件和已有备份。
