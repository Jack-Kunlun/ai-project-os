# v0.7.7：短信核验失败提示与供应商弹窗高度

## 本次变化

- 阿里云 PNVS 核验接口返回 HTTP 403、`Forbidden.NoPermission` 时，后台明确提示补充 `dypns:CheckSmsVerifyCode` 权限；不展示供应商原始错误、凭据或请求内容。其他供应商错误继续返回固定通用提示。
- 测试调用失败或过期时提示重新发送，并清除不可复用的测试凭证与验证码输入，保留供应商配置和测试手机号。错误验证码仍遵循现有次数限制；失败或过期的测试不能保存启用。
- 新增模型供应商弹窗最大高度调整为 704px，并受可用视口高度约束；表单间距收紧，能力说明默认折叠。标题和底部操作保持可见，保留焦点、Escape 与提交保护。

## 验收证据与边界

15 项定向协议、版本和发布状态机检查通过；完整 140 条迁移及 39 项隔离 PostgreSQL 认证检查通过，无跳过。数据库检查覆盖权限拒绝后的证明失效、重试提示、过期时不调用供应商、未验证时禁止保存；外部短信响应使用测试替身。

最终类型检查、7 个受影响文件的 ESLint、生产构建和性能预算通过。认证处理和生产更新入口经过独立 S4 审查；实际独立审查结论另行记录，不以本地测试替代。

实际 React/Tailwind 隔离浏览器确认：969px 高视口中模型弹窗高度为 704px，展开能力说明后高度仍受约束，底部操作可见，Escape 可关闭。隔离预览不提交真实凭据或发送短信。

2026-10-06，生产只读诊断使用保存的候选配置和合成核验输入，确认 PNVS `CheckSmsVerifyCode` 返回 HTTP 403、`Forbidden.NoPermission`。用户随后补充云端 RAM 授权、重新发送短信、核验并保存配置。16:48（北京时间），生产管理页确认 PNVS 配置版本 1、已启用、手机号认证可用，并显示“短信服务配置已保存并启用”。这验证了当前供应商的后台测试与启用流程；不代表手机号注册、验证码登录或注销的真实端到端流程已完成。权限要求见[阿里云官方核验接口](https://help.aliyun.com/zh/pnvs/developer-reference/api-dypnsapi-2017-05-25-checksmsverifycode)。
