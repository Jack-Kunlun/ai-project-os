# v1.0.12 — 修复 AI 自动整理的结构化输出

自动整理向 DeepSeek 明确请求 JSON 对象并关闭思考模式，让有限的输出预算用于有证据的候选内容。原文、模型和本次外发范围仍由用户确认，返回结果继续经过严格结构与逐字来源证据校验；冲突、改写和不确定内容保留待处理。

供应商明确报告输出截断时，任务返回专门的失败提示并保留原始资料，不采用不完整结果或自动重发。已返回且已知的真实 Token 用量仍先完成正常审计和结算。

发布工具同时兼容 containerd 将镜像摘要引用列入 RepoTags 的形式；只有与可信仓库、RepoDigests 和不可变镜像 ID 完全一致的引用才可识别，其他引用继续受保护。实际清理数量以发布维护回执为准。

本版本没有新增数据库迁移，清单仍为 146 条。正式发布复用精确提交的成功主分支 CI 和不可变镜像；源码门禁、生产健康及个人知识到项目的真实模型验收分别记录，不以其中一项代替其他结果。
