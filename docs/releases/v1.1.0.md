# v1.1.0 — 平台体验与智能问答重构

按已确认的高保真原型更新用户侧和管理平台，统一智能问答，并补齐三维知识图谱及登录页体验。实际部署结果以本次发布回执和公网 `/api/health` 为准。

## 平台与登录体验

- 用户侧保留工作台、智能问答、我的项目、我的知识四个全局入口。当前项目支持切换，项目计划、项目资料、项目概览、简报与调查、项目自动化、项目管理直接显示，栏目和内容随项目切换。
- 页面使用白灰底色、蓝色操作按钮和紧凑列表；新增、编辑、配置和执行保留明确操作入口。登录页同步视觉风格，支持桌面和手机布局，保留密码、短信及已配置的第三方登录流程、失败反馈与返回路径。
- 管理平台采用平台总览、用户与权益、配置中心、安全中心、运维中心五个直接入口，组内使用横向栏目，保留原有管理操作和逐次确认。

## 连续智能问答

- 统一选择全量可访问内容、个人空间或单个项目，同一会话可逐轮切换范围。
- 每轮保存完整问题、回答、当时范围、模型和引用快照；历史按会话组织，可重新打开并继续追问。
- 发送前展示实际外发资料、历史上下文和预计平台额度，并重新核对账户、项目、来源版本与模型路由。
- 历史仅本人可见。撤销项目访问后停止展示相关会话；只读或归档项目的历史仍可查看，但不能继续外发。结果未知时保留预留额度及审计记录，并阻止重复发送。
- 本次统一问答采用有界关键词资料匹配与平台默认生成模型；完整历史超过上下文预算时需要新建会话。原有语义索引能力保留。旧个人问答审计没有正文，不补造历史。

## 三维知识图谱与资料

- 我的知识提供全部知识、通用记忆和知识图谱。图谱通过三维坐标及透视展示真实来源归属、已确认事实和已记录关系。
- 支持旋转、节点拖动、画布平移、缩放、适应全图、重置与键盘操作。点击资料或事实进入对应来源详情；拖动不触发跳转，布局调整不改动知识关系。
- 密集场景以圆点显示，悬停、聚焦或选中时显示标题；较大范围分批展示。
- 项目资料保留资料、整理结果、识别任务三个栏目；识别与整理继续由后台队列处理，保留逐次确认与取消边界。

## 管理统计与升级

- 平台统计纳入统一问答及有平台预留证据的个人问答，排除个人 BYOK；管理端只读取安全聚合，不展示私人问答正文。
- 成功问答用量与轮次在同一事务保存，趋势按上海自然日统计，未知调用保持待核对状态。未接入的监控数据不会以示例值展示。
- 追加一条统一问答迁移，迁移清单从 147 增至 148 条，并扩展对应数据库主体权限与额度约束；保留已有用户、项目、资料和上传文件。

## 验证与现场边界

正式发布复用精确提交的成功主分支 CI 和不可变摘要镜像，覆盖默认测试与覆盖率、静态与构建检查、性能预算、隔离 PostgreSQL、认证、数据库主体、浏览器与可访问性、同镜像候选。上线结果由发布回执另行记录。[此前本地验收记录](v1.1.0-local-acceptance.md)仅作为历史证据。

本地示例项目、资料及知识数据不进入生产。浏览器问答交互使用响应夹具；持久化、权限和用量由真实 PostgreSQL 验证。真实模型、Git、OIDC、短信和第三方 MCP 仍按部署配置分别现场验收，本版本不把测试夹具当作外部服务验证。
