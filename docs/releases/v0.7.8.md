# v0.7.8：优化登录与注册表单

用户名密码和手机号验证码登录均移除“记住我”复选框。手机号模式移除该行占位；密码模式保留右侧“忘记密码”入口。登录请求沿用原默认的 `remember=true`，服务端认证、防刷、会话时长规则不变。

手机号登录改为上下两行：手机号独占一行，验证码输入框及获取验证码按钮在下一行；三个控件统一为 56px。共享验证码组件提供可选的大尺寸；注册及注销的默认尺寸沿用现有设置。

注册表单的用户名独占第一行，手机号和短信验证码在下一行并排，小屏幕自动上下排列。注册页移除 GitHub 注册登录按钮、分隔线及相关说明；GitHub 登录入口保留在登录页。
