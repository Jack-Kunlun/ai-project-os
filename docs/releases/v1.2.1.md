# v1.2.1 — 工作台与智能问答体验修正

本次补丁按确认原型修正工作台、知识导航和跨页面智能问答，保留现有接口、权限、资料范围及逐次外发确认边界。

## 使用体验

- “需要你关注”和“常用操作”采用一致的外层底色、白底条目、边框、圆角和间距；标题下均有说明，待关注数量紧跟标题，通知中心与使用流程入口位于底部左侧。
- 常用操作可添加当前项目资料、新建个人知识或发起问答。切换当前项目后资料入口随之更新；当前项目不可用时先选择可用项目。
- 新建问答会话准备新的问题草稿并聚焦输入，既有会话与引用保留。首条问题完成后，新会话进入历史。
- 业务弹窗和抽屉中的问答打开独立顶层窗口。关闭问答后返回原业务表单与焦点，保留原输入；问答内部的确认与历史仍可正常使用。
- 并排停靠仅让正文让出空间，头部工具与账户位置保持稳定。窗口放大、完整页面和停靠使用不同图标，提示同时支持悬停与键盘焦点。
- 知识图谱使用独立菜单，移除我的知识与图谱页面之间重复的页签。

## 验证与发布边界

前端共享图标和重复的记忆质量客户端使用既有共享分包；ESLint 仅忽略已由 Git 忽略的六个根级生成目录，源码与测试继续检查。性能预算不提高。

本地验证覆盖工作台对齐、当前项目入口、问答新会话及顶层窗口、表单草稿返回、头部几何、图谱菜单、中英文与深浅色代表状态，以及窄屏布局和可访问性。正式发布以本次精确主分支 CI、CI 发布的同一不可变摘要镜像、生产回执和公网健康为准。本地示例与隔离验收数据不进入生产。
