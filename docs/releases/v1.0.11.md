# v1.0.11 — 个人知识到项目流程与发布资源保护

个人知识新建或导入保存后直接打开内容，并集中提供提问、索引管理和放入项目资料的下一步入口。放入项目仍需明确选择目标、复制正文并在项目资料窗口确认保存；个人原文保留，正文不会进入跳转 URL 或浏览器存储。个人问答与个人索引仍遵循已有模型配置和确认要求。

项目资料、整理核对、索引问答和安排任务通过简洁流程入口相连。导入后可在同一窗口继续 AI 整理，已保存资料可从详情恢复整理；本次外发范围和模型仍需确认。符合逐字原文证据及既有准入规则的内容形成事实，冲突、改写和不确定内容保留待处理。问答索引单独确认更新，事实不会自动变成任务。

索引和问答入口会定位到对应操作区，索引就绪后可在同一页继续提问。项目计划保持手动创建、指定负责人和验收标准，并按既有规则关联完成证据。

正式发布复用精确同 SHA 的成功主分支 CI 与不可变摘要镜像。发布后维护保护当前及上一版本、已有容器、数据卷、配置和数据库账本，只按冻结 ID 范围回收可删除资源；缓存目标为 2 GB，受保护记录、超额及未核实结果分别报告，不为满足目标扩大删除范围，也不将维护失败冒充达标。

本版本没有新增数据库迁移，清单仍为 146 条。常规发布不执行备份或恢复演练，已有业务资料和历史备份保留。实际上线版本、精确提交、镜像及健康结果以正式发布回执和公网健康为准；线上个人知识到项目的真实模型流程另行验收。
