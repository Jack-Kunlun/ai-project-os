# v0.8.0-dev.1 — 账号恢复与手机号管理

## 更新内容

- 登录页新增“忘记账号或密码”：验证已绑定手机号后显示原登录名并重设本地密码，随后重新登录。未知号码不会创建账号。
- 个人中心和管理员账户新增首次绑定、换绑入口。首次绑定验证当前密码和新号码；换绑同时验证原号码和新号码，保留原账号、工作区及项目归属。
- 密码设置、密码修改、恢复、绑定与换绑同步推进安全版本、撤销会话、废止旧短信证明，并写入不可变安全审计。数据库约束拒绝缺少有效证明和审计的直接变更。
- 整合 v0.7.18 的浏览器 broker 取消安全修复与验收材料，保留生产浏览器开关关闭。

沿用大陆 +86、发送前图形验证码、现有三种短信供应商及持久化预算。不包括邮箱找回、原号码不可用时的申诉换绑、解绑、短信 MFA、管理员代改或账号合并。手机号本身作为登录名的账号，需先修改登录名再换绑。
