# AI Project OS 需求基线

基线：B-20261102-01；整理日期：2026-11-02。本文分开记录已有产品说明与本次授权目标。已有能力摘自当前源码文档，并不表示本轮逐项完成了运行验收。

## 产品定位及现有范围

AI Project OS 是可自行部署的知识与项目工作台，将资料、问答、来源证据和下一步工作组织在一起。当前应用说明见 [应用 README](../../README.md) 与 [用户指南](../../docs/user-operation-guide.md)。

| 领域 | 当前文档描述的范围 | 本轮证据边界 |
| --- | --- | --- |
| 个人知识 | 文本与文件导入、检索、围绕资料提问、知识图谱 | 已索引说明及页面入口，未逐场景运行验收 |
| 项目协作 | 项目、资料、整理结果、计划、简报、成员及权限 | 同上；保留数据与服务端权限边界 |
| 统一问答 | 会话、范围选择、引用、历史与浮窗；当前主入口按关键词选择资料 | 不宣称统一问答已采用全部高级语义检索能力 |
| 外部来源 | 配置后的 Git、网页、本地文件夹及受控动作/MCP；区分外部读取与本项目对外导出 | 网页模式与 MCP 导出各有启用/审核限制，见 MODULE-BOUNDARIES；真实外部服务本轮未验证 |
| 管理平台 | 模型与能力、账号、权益额度、审计及运行维护 | 不用界面存在证明配置或业务调用成功 |
| 外观 | 中文/英文、浅色/深色/系统主题及窄屏适配 | 用户已报告一致性缺陷，待新一轮完整视觉验收 |

完整产品能力、代码定位及历史交付见 [已有能力与完成记录](DELIVERED.md)。该清单包含 12 个能力分组与 11 组版本演进，不能由分组数量计算完成率。当前批量模型能力已有 v1.2.19 实现记录；上传限制等旧指南差异已登记 T-017，不能继续作为当前需求依据。

## 规则与约束

- 当前原型和最新明确修订是设计输入；若新旧记录冲突，标明被替代部分；未明确部分不凭主观偏好重设计。
- 功能原型是示例，不能证明 API、权限、额度、模型或外部服务已接入。
- 保留应用现有认证、RBAC、凭据保护、外发确认、数据来源与审计；视觉整改不授权改变这些行为。
- 每条需求的正常、空、加载、错误、边界、权限与恢复场景按适用性列出；不适用需说明原因。
- 用户文案和运行界面只描述当前可用能力；规划不得伪装成上线能力。
