# v1.2.7 — 统一两种登录表单高度

用户名密码登录与手机号验证码登录共享按内容自适应的表单区域。两种方式切换时，登录按钮与卡片保持相同高度；较长的英文说明和验证码状态可以自然换行，不裁切内容。隐藏表单禁用并退出焦点与可访问性树，原有登录请求、挑战校验与账号跳转保持不变。

验证码有效期说明、发送状态、登录错误提示与后续操作之间保留至少 12px 留白。用户名、密码输入文字与图标采用相同内边距，创建账号、其他登录方式及第三方入口继续保留既有间距。

定向验收覆盖中文浅色和英文深色、1440px、390px 与 320px 窗口，以及初始、验证码已发送和发送受限状态。短信请求使用受限隔离环境拦截，不向真实手机号发送短信。不新增依赖、接口、权限或数据库迁移，迁移清单保持 150 条。

代码与本地检查不代表生产已切换；线上状态以精确提交 CI、不可变镜像、部署回执和公网健康检查为准。
