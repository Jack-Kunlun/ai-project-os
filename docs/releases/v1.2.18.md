# v1.2.18 — 操作弹窗、资料选择与归档项目快捷操作

操作弹窗统一标题与关闭入口，正文独立滚动，操作按钮固定在底部并与智能问答分行。项目状态与审计抽屉改为易读的指标网格和全宽事实列表，补齐展开内容底部留白，减少重复标题与嵌套卡片。

整理已有项目资料支持全选、取消全选和选择计数。所选资料沿用每批两份的既有外发摘要与授权规则，先展示全部批次摘要，经确认后依次执行；运行期间不能切换选择或复用其他范围的摘要。

已归档项目在“我的项目”列表增加永久删除入口。继续要求项目名称、Owner 权限和版本校验；项目状态变化后必须重新读取并重新确认，运行中任务、上传和待处理动作等阻止原因保留原有提示。

语义索引输入过大时显示明确原因，并保留服务端已有索引的可用状态。本版本没有实现大项目的可恢复索引构建，也没有提高资料数量、文本或请求时限。

布局先更新恢复的本地原型，再实现并验证。原型恢复范围与历史缺口记录在原型目录的 `RECOVERY.md`，不将恢复结果描述为历史文件的逐字节副本。

本地验证覆盖 104 项聚焦合同、Lint、类型、生产构建与原有性能预算，以及 8 项隔离浏览器用例（中英文、深浅主题、桌面/窄屏、固定操作区、资料全选与摘要确认、真实归档版本冲突及删除）。发布前复核另补充了后台任务 409 与版本过期 409 的区别，由提交后 CI 重新验证最终源码。

无服务端 API、权限规则、依赖、Schema 或迁移变化，迁移清单仍为 150 条。正式发布复用精确同 SHA 的成功主分支 CI 和不可变镜像，生产状态以部署回执、公网健康及 GitHub Release 为准。
