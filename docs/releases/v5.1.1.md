状态：内部研发里程碑（非正式发布）

V5.1.1 是 V5.1.0 的兼容性质量补丁，不新增数据库迁移、不扩大 Action Engine、MCP 或项目智能体权限，也不改变正式部署的数据模型。

## 质量与交付门禁

- 默认测试增加源码覆盖率门禁，覆盖全部 `src` TypeScript/TSX；行、分支和函数覆盖率最低要求分别为 60%、78% 和 67%。
- 生产浏览器 E2E 对 setup、Dashboard、项目列表、使用指南和 MCP 连接页执行 WCAG 2.2 A/AA 自动扫描。
- 增加确定性的生产客户端 gzip 体积预算，约束共享 JavaScript、最大单文件、全局 CSS、全部静态客户端资源和五个关键路由。
- 增加隔离本地 Compose 候选门禁，构建 app、worker、migrate 镜像，核对 50 个迁移、OCI 版本、容器与 API 健康，重启后复验并精确清理候选资源。
