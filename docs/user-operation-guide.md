# 普通用户操作指南

本指南面向项目成员、项目 Owner/Editor、工作区 Owner/Admin，说明当前页面能力和安全边界。它不要求普通用户配置平台凭据；平台模型、Git/MCP 连接器、会员资格和服务器备份由系统管理员在独立管理工作台维护。

## 1. 先理解边界

### 1.1 资料、候选与事实不同

- 文件、网页、代码仓库和手工原文是可追溯的 `ProjectSource` 资料。
- 自动抽取只产生带 `sourceId` 和精确原文摘录的候选，不会直接变成可信事实。
- 人工确认后的 `ProjectItem` 才进入当前事实视图；驳回记录仍保留在审核历史。
- 语义搜索和 RAG 返回证据片段，回答仍需要人核对，不能把模型文字当作系统状态。

### 1.2 外发需要当次确认

索引、简报、图片识别和自动抽取等模型任务会显示供应商、模型和输入范围。只有页面上的当次确认通过后，待生成片段才会发送；复用已有片段不会再次外发。自动化不会绕过这个确认。

### 1.3 受控动作不是任意智能体

动作中心只开放固定的只读能力。MCP 还需要管理员认证精确工具、项目 Owner 授权和每次审批。没有 Shell、代码修改、Git 写入、部署、stdio、本地子进程或 MCP 写操作。

### 1.4 页面入口与子页

项目内固定六个一级入口，任务、资料、仓库和后台作业详情是从一级入口进入的必要子页。返回按钮默认回到产生它的上一级；从通知进入详情时返回通知中心。

## 2. 账号、工作区和权限

### 2.1 登录与角色

登录后先打开 Dashboard，只会看到自己有权限访问的项目。工作区角色和项目角色分别判断：

| 角色 | 当前范围 |
| --- | --- |
| workspace Owner | 管理所属工作区成员、邀请、企业登录和工作区内项目，可授予工作区 Owner |
| workspace Admin | 管理所属工作区成员、邀请和工作区内项目，不能修改 Owner |
| project Owner | 读取、编辑、归档/恢复当前项目，并管理项目策略、授权和审批 |
| project Editor | 读取并修改当前项目内容，不能归档/恢复 |
| project Viewer | 只读访问被授权项目 |
| Member | 只有被单独授予项目后才能进入对应项目 |

工作区 Owner/Admin 不等于系统管理员，不能访问平台模型、Git/MCP 连接器或用户会员管理。系统管理员使用单独的 `/admin` 管理工作台。

### 2.2 接受邀请

邀请链接由工作区 Owner/Admin 创建，有效期为 7 天且只在创建响应中显示一次。邀请对象登录已有账号，或在允许自动建号时通过企业登录创建账号，再打开链接接受。邮箱限定邀请必须完全匹配；系统不会仅凭相同邮箱静默合并不同身份。

### 2.3 创建项目

只有系统管理员或当前工作区 Owner/Admin 可以创建项目。普通 Member/Viewer 从获授权项目开始，不会通过隐藏按钮获得创建权限。

有权限时进入 Dashboard 或“项目”，选择“新建项目”，填写名称和可选描述。项目会隔离资料、计划、AI 路由、记忆、自动化、操作和审计。归档项目只读，恢复后才可继续修改。

## 3. 项目六个一级入口

项目内导航固定为以下顺序：

1. **项目概览**：读取当前有效事实、问题、风险、关系和计划健康度计算出的状态。
2. **项目计划**：维护目标、工作项、负责人、日期、验收标准、依赖和证据。
3. **项目资料**：接入文本、文件、网页、文件夹和代码仓库；列表精简，点击条目进入详情。
4. **AI 工作台**：在当次确认后运行抽取、索引、检索、引用式问答和只读调查。
5. **项目自动化**：配置来源维护、记忆质量和计划健康提醒，查看 Worker 任务结果。
6. **项目管理**：审核候选、治理事实关系和状态、查看动作审批与项目 AI 用量。

必要的资料详情、任务详情、候选审核、代码仓库扫描和通知详情均属于上述入口的子页，不是额外的一级导航。

## 4. 项目概览与项目计划

### 4.1 项目概览

概览只把当前已确认、未退役、在有效期内且未被替代的事实纳入状态。问题、冲突、风险和计划健康度由本地确定性规则计算，不是模型猜测。事实卡片可以打开来源、版本和证据详情，历史内容仍保留但不参与当前状态。

从概览按六个一级入口进入下一步。需要查看单条资料、任务、仓库或状态审计时，使用对应卡片的详情链接；不要把历史详情页误认为另一个项目工作区。

### 4.2 计划与工作项

在“项目计划”中创建目标和工作项。工作项可以设置优先级、说明、目标、负责人、期限和独立验收标准：

- 负责人只能选择当前项目可编辑成员或工作区 Owner/Admin。
- 进入“进行中”前必须有负责人和验收标准。
- 进入“已完成”前必须至少关联一条有效活动证据。
- 已完成和已取消是不可改写终态；并发版本过期时页面不会覆盖他人的更新。
- 智能体建议只会以带引用的 `proposed` 工作项出现，必须人工接受并补齐负责人、验收和证据。

仓库变化信号只提供确定性变更清单。Editor/Owner 需要人工选择“关联并确认”或“忽略”，不会自动生成工作项、调用工具或修改代码。

## 5. 项目资料

### 5.1 手工资料、文件与文件夹

“项目资料”可以添加文本、TXT、Markdown、JSON、CSV、PDF、DOCX、PPTX、XLSX、PNG、JPEG 和 WebP。资料列表展示来源类型、状态和摘要；点击条目进入详情查看正文、解析状态、精确来源和审核历史。

当前默认限制包括：一次最多选择 10 个文件，单文件最多 25 MiB，图片最多 10 MiB/2000 万像素，单次 multipart 请求最多 30 MiB。项目、工作区和部署的字节与保留对象也有独立上限；服务端会在读取正文前核验配额。软删除但仍保留的 blob 继续计入预算，恢复或重复提交相同内容不会重复计费。

文件登记和解析任务在同一事务内提交。解析失败保留安全错误码和原文件，不会写入不完整资料；Editor/Owner 可在详情中重新解析。选择本地文件夹只上传明确选择且格式受支持的文件，不会获得任意本地文件系统权限。

文本和 Office 文档优先本地解析。图片或扫描 PDF 需要在 AI 工作台配置视觉路由、核对待发送片段、勾选本次确认，再逐片段编辑、接受或驳回。PDF 在分配渲染画布前限制页边长和像素预算；Office 内嵌图片、音频和视频当前不会识别。

### 5.2 网页来源

在“项目资料 → 外部资料”添加网页或本地文件夹来源。公开网页默认要求 HTTPS，内网页面必须明确开启受信任私网访问。系统会固定 DNS、逐跳检查重定向、阻止云元数据地址、限制响应体并移除脚本和不可执行内容；新版本完整成功后才切换活动指针。网页抓取不执行 JavaScript、不登录站点，也不支持自定义 Cookie 或请求头。

### 5.3 代码仓库

项目首次 Git 仓库接入由系统管理员在验证平台连接后完成；普通用户不会请求全局 Git 连接列表，也不能把任意平台连接交给项目接口。已关联仓库的项目成员可查看仓库摘要，并按当前项目权限执行既有受控扫描。

仓库扫描固定分支 commit，只读取明确的目录和文本文件，完成全部校验后原子发布快照；失败不会替换上一代活动快照。仓库路径、分支、凭据权限、CA/known_hosts 或 DNS 地址变化导致读取失败时，请联系系统管理员重新验证平台连接。Git 通用连接只读取代码和文本，Issue、PR、Release 等扩展资料仍走既有 GitHub 专用入口。

## 6. AI 工作台、记忆与检索

### 6.1 项目 AI 路由

在 AI 工作台查看当前项目允许的视觉、抽取、向量和生成路由。平台模型由系统管理员配置并验证后供项目选择；普通用户不能保存平台 API Key。切换生成或视觉模型影响后续任务，历史来源仍保留原供应商和模型。切换向量供应商、模型或维度会使活动索引失配，需要重建。

### 6.2 自动抽取与人工审核

选择资料后核对输入清单和传输范围，再确认外发。系统只接受结构合法且引用的连续原文确实存在的结果。任务详情只展示来源数、新增候选、重复/拒绝/证据校正等安全摘要，不展示原始模型载荷。只有任务成功且确实产生候选时才显示“进入候选审核”；候选区支持逐条或批量确认，服务端会做并发校验。

### 6.3 统一语义索引、搜索、RAG 和只读智能体

索引覆盖活动的人工资料、文件片段、网页修订、仓库文本和代码快照。以下变化需要重建：

- 新增或更新资料、网页、文件或代码快照；
- 接受或撤销影响语义内容的来源；
- 更换向量供应商、模型或维度。

只有全部向量成功持久化后才切换活动索引。语义搜索返回项目内原文片段、路径、版本和分数；RAG 只能引用本次检索集合中的不可变证据。只读智能体可以读取确定性项目状态、事实、语义记忆和仓库状态，但不能修改状态、执行 Shell、写代码、写 Git、调用写工具或部署。

### 6.4 记忆质量与世界状态

“项目管理”中的记忆质量检查使用本地确定性规则识别重复、冲突、过期、证据不足和低置信度。处理结果会留下审计记录，不会自动调用模型。

项目状态只纳入当前有效事实。Viewer 可读取状态和审计；Editor/Owner 可以在有证据时建立、退役事实关系和替代链，并固化状态快照。关系固定双方当时的精确修订，事实变化后显示为陈旧；替代链只允许同类型、无环的向前链，旧事实不会被删除或恢复为当前版本。

## 7. 自动化、通知与动作审批

### 7.1 自动化

项目 Owner 可以配置仓库同步、网页刷新、记忆质量和项目计划健康提醒。Worker 持久化租约、心跳、失败码和连续失败次数；连续失败达到阈值后规则会暂停。归档项目会暂停活动规则，恢复后不会自动重启。

计划健康检查只读本地数据库，不调用模型或外发项目内容。通知发送前会重新核对接收者当前项目访问权，失去权限或被停用的账号不会继续收到项目摘要。

### 7.2 通知与任务详情

通知中心汇总成功、失败、记忆质量、计划健康和外发待确认消息。点击“查看详情”立即标记通知为已读，已读消息自动从未读列表消失。任务详情只显示安全结果摘要，未知结果需要人工收口，不能当作成功。

普通任务详情的返回按钮回到产生它的上一级项目页；从通知进入的详情返回通知中心。自动抽取任务成功且候选数大于零时，从详情进入候选审核区继续处理。

### 7.3 动作与审批

动作策略分为自动执行、每次审批和禁止执行。当前默认能力如下：

| 能力 | 访问范围 | 默认行为 |
| --- | --- | --- |
| 同步代码仓库 | 只读外部访问 | 每次审批 |
| 刷新网页来源 | 只读外部访问 | 每次审批 |
| 检查记忆质量 | 本地数据库 | 自动执行 |
| 调用 MCP 只读工具 | 受控远程访问 | 每次审批，不可自动执行 |

动作会固定项目、能力、规范化输入、输入指纹、风险和策略快照。等待审批的动作 24 小时后过期；项目 Owner 审批时会再次核对版本和输入指纹。Worker 租约过期、MCP 定义/网络/凭据漂移或项目归档都会失败关闭，不会自动重复外部读取。动作申请、审批、领取和终态均进入不可变审计。

## 8. 治理、导出与安全

“项目管理”可以审核候选、查看模型路由历史、核对 7/30/90 天调用和 Token 用量，并在有不可变证据时人工收口未知任务。归档前要处理排队、等待确认、运行中和待人工收口任务；归档不删除历史。

受限 JSON 导出包含项目正文、文件元数据和审核文本，不包含上传二进制、系统路径、凭据、向量和完整运行载荷。导出不是灾难恢复备份。不要在项目资料、Issue、描述、日志或 URL 中写入密码、API Key、Token、私钥或数据库连接信息。

普通用户不执行服务器备份。数据库、主密钥和 uploads 必须由管理员在一致窗口一起备份和恢复；不要使用 `docker compose down -v`。

## 9. 常见问题与用户侧故障排查

| 现象 | 处理 |
| --- | --- |
| 模型不能选择 | 检查项目路由是否就绪；平台模型状态由管理员维护，联系管理员重新验证 |
| Git 仓库无法读取 | 检查项目权限、路径、分支和最近同步错误；连接状态、DNS、凭据或信任材料变化时联系管理员 |
| 网页刷新失败 | 确认页面无需登录或 JavaScript；内网来源需要管理员明确授权，云元数据地址不可放行 |
| 图片或扫描件停滞 | 检查视觉路由、待发送片段和当次确认，再逐片段审核 |
| 自动抽取无候选 | 查看任务安全摘要；没有候选时不会出现审核入口，失败/未知状态不能当作成功 |
| 索引要求重建 | 用当前项目向量路由重新建立索引，确认模型和维度未变化 |
| 通知仍在未读 | 进入查看详情会自动标记已读；刷新通知中心即可移除 |
| 动作等待或失败 | 联系项目 Owner 审批；过期动作重新创建，失败后先看安全错误码和审计，不自动重试 |
| 项目不能归档 | 先处理运行中任务、自动化和动作；等待确认/未知任务需要人工收口 |
| 用量与账单不同 | 页面只记录受审计调用和 Token，不维护价格、折扣或缓存计费，最终以供应商账单为准 |

更具体的部署、凭据、备份和服务器故障处理见[管理员操作指南](./admin-operation-guide.md)。旧入口[操作手册索引](./operation-manual.md)只用于兼容导航。
