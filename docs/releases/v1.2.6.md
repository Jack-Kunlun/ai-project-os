# v1.2.6 — 完善登录留白与图谱可视范围

登录密码框与用户名框采用相同的图标与输入文字间距。找回密码、登录按钮、创建账号提示与其他登录方式之间保留清晰的垂直留白，保持链接的可点击区域；错误提示出现后允许自然扩展。

窄屏下，知识图谱上方的范围与视角控件可能使画布只显示一部分。“适应全图”现在同时将画布带入可视区域，预留顶部栏与底部悬浮问答入口的空间，避免适应后的节点被固定按钮挡住。视角使用当前画布尺寸计算，兼容刚调整窗口大小的情况。

已经完整可见的画布保持原页面位置，节点拖动、缩放、旋转、来源与事实详情继续沿用原有交互。此修复不更换悬浮问答入口的设计，也不新增依赖、接口、权限或数据模型；迁移清单保持 150 条。

代码与本地检查不代表生产已切换；线上状态以精确提交 CI、不可变镜像、部署回执和公网健康检查为准。
