# v1.2.19 — 批量配置模型能力与测试额度说明

“模型与能力”支持勾选、全选和统一设置所选文字能力模型。确认本批范围后，可逐项测试并立即启用通过项，也可仅测试后使用有效期内的结果启用；失败保留原配置，未知结果停止后续项，不自动重试。更换向量模型或维度仅在启用时确认索引影响。每项测试和启用沿用服务端独立凭据、请求标识和五分钟证明绑定，重试启用复用原证明。

“探测预算”更名为“模型测试额度”，明确限制的是周期内连通性测试请求次数，不是用户 Token 或人民币余额。每次单项能力测试最多计一次，六项一次全测最多六次；再次手动测试另计，供应商可能另收 Token 费用。管理员可在模型页直接设置最大次数、有效期及高级告警阈值，无需跳转。新周期立即替换旧周期，未来开始时须等待生效，剩余次数不结转。

布局和流程先更新本地原型，再实现。中英文、管理员指南和当前操作说明同步更新；框架入口与共享样式映射去重，保留原有性能门槛。

功能源码本地验收为 47 项受影响测试、相关 ESLint、类型检查、Node 生产构建与性能预算通过（全部静态资源 869.5 KiB / 871.25 KiB）。复用相同文件哈希的验收证据，提交前补充版本身份检查。不启动本地 Docker 验证环境，不调用真实供应商；浏览器场景使用模拟接口定义，由正式 CI 按累计影响计划执行，不将本地静态检查描述为浏览器验收。

发布来源的只读健康核对对明确的瞬时连接错误、429 和 5xx 最多重试一次；仍拒绝不健康、未知来源、重定向和无效响应，不放宽版本及同提交 CI 证明。该重试不适用于模型探测或写操作。

无服务端 API、授权规则、依赖、Schema 或迁移变化，迁移清单保持 150 条。正式发布复用精确同 SHA 的成功主分支 CI 与不可变镜像；发布和线上健康以实际回执为准。
