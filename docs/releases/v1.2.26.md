# v1.2.26 — 全系统页面、操作弹窗与异常状态样式统一

本版本统一普通用户端和管理端的页面、表单、导航、按钮、操作弹窗以及加载和读取失败状态，修正此前改版遗留的旧样式。

## 主要变化

- 公共组件与各页面统一使用当前设计基线，覆盖浅色/深色、中英文、桌面和窄屏布局。
- 统一操作弹层的标题、字段、底部按钮、焦点和滚动表现，修正问答历史错误区域、个人资料字段及 MCP 入口的布局和可读性。
- 补充全页面、父级导航、权限守卫与异常状态回归；隔离浏览器验收显式开启 MCP 条件页面，保持生产功能开关及授权要求不变。

## 验证与发布边界

本地 C7 UI 验收覆盖 77 个入口、539 次路由访问、175 次父级导航、45 项守卫及 520 条状态记录，实际审阅 358 张候选截图。默认浏览器 85 通过、6 配置跳过；认证启用配置 6 通过、2 相反配置跳过。完整证据见 [UI 整改验收报告](../project/UI-REMEDIATION-20261115.md)。

此前候选的正式 CI 因隔离环境未开启 MCP 页面失败；本版本修正该环境，重新以精确提交执行 CI、同镜像浏览器验证和手动发布。实际候选与上线结果记录在 [E-024](../project/EVIDENCE.md#e-024--v1226-发布候选与线上回执)，不以历史本地验收替代正式 CI 或生产回执。

本版本不新增数据库迁移，不改变生产认证、权限、模型外发或 MCP 默认启用策略。真实模型、Git、OIDC、短信及第三方 MCP 服务未作为本次 UI 发布的现场验证内容。常规发布沿用现有不可变镜像流程，不要求新增备份或恢复演练。
