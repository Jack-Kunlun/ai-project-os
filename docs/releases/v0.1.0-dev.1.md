# AI Project OS v0.1.0-dev.1 预发布说明

发布日期：2026-09-03

状态：GitHub prerelease / 内部开发基线 / 非生产版本

`v0.1.0-dev.1` 用于固定 0.2.x 产品体验与权限改造前的可追溯代码基线。它不是正式公开版本，不标记为 Latest，也不会进入生产部署通道。

## 当前能力

- 提供 Dashboard、项目管理、项目资料、事实与候选审核、计划、状态、动作审批和自动化等项目工作流。
- 支持文件、图片、网页和 Git 仓库等资料来源，以及受约束的 AI 抽取、索引、检索、简报和只读智能体链路。
- 支持工作区与项目 RBAC、OIDC 和 GitHub 登录、加密外部凭据、模型调用审计及平台额度预留与结算。
- 提供管理员工作台，用于平台级模型、Git、OIDC、MCP、备份和运行状态治理。
- 包含 54 个 Prisma 迁移以及应用、Worker、PostgreSQL 的隔离本地候选发布门禁。

## 安全与发布边界

- 首个正式 `v1.0.0` 发布前，生产部署工作流保持静态禁用；本预发布不会部署或修改正式实例。
- AI、Git、OIDC 和 MCP 凭据保存在运行环境中，不随源码、标签或 Release 附件发布。
- Release 不附带数据库备份、secrets/uploads 卷、用户数据或凭据文件。
- 真实外部模型、Git 服务、OIDC Provider 和第三方 MCP 仍需在目标环境使用实际凭据分别验收；本地替代服务与无凭据测试不等同于现场联调。

## 已知产品限制

- 当前用户等级、免费额度、会员权益和个人模型配置尚未形成完整一致的产品模型。
- 当前 BYOK 模型仍带有工作区共享语义；Git/MCP 连接也尚未完成严格的用户私有所有权与显式项目委托模型。
- 管理员可维护平台模型连接，但当前尚无完整的全局默认模型路由及面向用户的稳定回退策略。
- 以上限制将在 `0.2.x` 开发线按权限、数据迁移、服务层、用户体验和管理员治理的顺序改造。

## 验收口径

发布标签只允许指向同时满足以下条件的提交：

- `package.json`、`src/lib/version.ts`、Dockerfile OCI label 与运行健康接口均为 `0.1.0-dev.1`。
- Prisma 与迁移校验、类型检查、Lint、覆盖率测试、完整 PostgreSQL 门禁、浏览器/WCAG、性能和隔离 Compose 候选门禁通过。
- GitHub CI 对标签指向的精确提交成功，且生产部署工作流未运行。

具体提交 SHA、CI 链接和本地候选结果记录在对应 GitHub Release 中；代码、CI、容器候选和真实外部集成是彼此独立的验收边界。
