# v1.2.4 — 短页滚动与管理端原型一致性修正

短页面不再因悬浮问答按钮的统一底部留白产生多余滚动；真实长页面仍保留按钮避让空间，并在内容、路由或窗口尺寸变化后重新判断。

平台模型页面使用紧凑的连接与能力列表，查看连接及配置能力从抽屉打开。管理端弹窗对齐用户端的宽度、标题和按钮样式，手机号修改使用统一弹窗，关闭时清除密码、验证码与验证挑战等临时状态，请求进行中保留关闭保护。

英文供应商目录、会员操作、账户会话数、保存按钮及分页文案使用对应上下文；窄屏额度操作区允许说明和提交按钮分行。

旧页面及兼容入口的静态日期按当前语言显示，保留原有时区和日期选项。资料预览中的长链接允许换行，图谱透明节点容器允许指针穿透，点击可见知识点继续打开其详情。

此版本不新增依赖、接口或迁移，不改变验证、权限、模型测试或额度确认要求。迁移清单仍为 150 条。源码版本不代表已经部署，线上状态以发布回执和健康验收为准。
