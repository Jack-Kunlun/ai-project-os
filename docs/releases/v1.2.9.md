# v1.2.9 — 操作控件与通知页布局统一

业务操作控件统一常规按钮 40px 高、紧凑按钮 32px 高，弹窗关闭按钮为 32px；操作组间距统一为 16px。项目详情与任务详情沿用一致的返回行布局。

通知中心筛选改为带底边强调的文字页签，并支持窄屏横向滚动。初始化设置页复用公共信息页的页面结构和表单样式，避免旧页面外层留白与共享布局重复叠加。

这些调整只涉及界面表现，不改变认证、权限、业务操作、接口或数据行为。本版本不新增依赖或数据库迁移；迁移清单为 150 条。

静态客户端 gzip 总量实测为 892,044 bytes（约 871.1 KiB），相较原 870 KiB 增加 1,164 bytes（约 1.1 KiB）。经用户接受，总量预算调整至 871.25 KiB（892,160 bytes），实测余量为 116 bytes；关键路由、共享脚本、最大文件和 CSS 阈值保持不变。

本说明记录当前源码候选，不代表已经发布或生产已运行该版本。生产版本仍以正式发布回执和公网 `/api/health` 为准。
