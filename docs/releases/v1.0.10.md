# v1.0.10 — 受限生产缓存维护

本源码候选为现有「发布正式版本」Workflow 增加 `cache-inspect` 和 `cache-clean` 模式，复用 production 环境中的 SSH 凭据、精确主分支 CI、固定工具更新入口及生产发布锁。维护模式不创建版本标签或 GitHub Release，不切换应用、不运行迁移。本次维护保持线上 1.0.9；未来如需发布 1.0.10 应用，仍由用户选择默认 `release` 模式手动发起。

缓存检查分别报告共享/私有与可回收/受保护四类记录。清理只处理 root 保存的短期计划中、再次核对后仍可回收的精确记录 ID；新出现、变为占用中或内容变化的记录不会自动纳入。共享记录的标称大小与文件系统可用空间净变化分别记录，不将缓存元数据删除声称为等量磁盘释放。

维护前后验证当前和上一版本镜像、既有容器、数据卷、配置、应用版本及数据库账本；不删除镜像、容器、数据卷或业务数据。来源、工具、保护快照或计划有效期不符时停止清理。原始命令描述、环境变量和 SSH 凭据不进入诊断报告。

标签不完整或不匹配的历史镜像单独列入额外保护快照，以 ID 和元数据哈希核对，报告只输出固定原因码；不能将它们视作当前或上一版本的可信镜像。

源码版本推进是现有工具更新协议要求的前进候选，不表示 1.0.10 已上线。无新增数据库迁移，清单仍为 146 条。实际分类、删除数量、空间变化和保护结果以维护 Workflow 的 `production-cache-maintenance` 产物与公网健康为准。
