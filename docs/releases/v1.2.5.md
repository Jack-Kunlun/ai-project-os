# v1.2.5 — 同步概览、页签与认证原型

图谱的项目分页与范围控件放在同一工具栏，仅多页时显示；关系图例按需展开，保留来源归属、事实依据和来源版本变化的真实含义。数据较多时仍说明预览边界，切页继续保留个人来源。

项目概览将目标与动态、工作与继续入口分别按行对齐，事实区使用全宽；窄屏改为连续单列阅读。项目管理、资料、简报与调查及个人知识的主要页签滚动后停在顶部栏下方，保留横向切换与原有权限控制。

工作空间选择器统一外框、键盘焦点、头像与名称，长名称自然换行。选择仍使用现有可访问工作空间接口，切换后进入工作台；移动导航层级高于吸顶页签，点击外部和 Esc 可收起。

兼容入口 `/projects?create=1` 保留创建意图，进入项目列表时直接打开创建弹窗；其他参数不透传。

登录、注册和找回使用同一紧凑认证版式。邮箱或手机号注册分为联系方式与账号设置，手机号找回分为验证信息与新密码；第一步只检查输入格式和验证挑战是否已取得，不表示服务器已完成身份验证。最终提交保持现有接口、完整挑战与验证码校验、密码规则和服务器原子处理。未配置验证通道时保留明确不可用提示，用户名密码兼容注册仍按既有配置工作。

正常桌面与手机高度避免不必要的页面滚动；低高度窗口和错误信息展开后保留自然滚动。中英文、浅深主题共用尺寸与对齐规则，来源原文保留原语言。

本次不新增依赖、API、权限、数据模型或迁移。迁移清单保持 150 条。代码与本地检查不代表生产已切换；线上状态以精确提交 CI、不可变镜像、部署回执和公网健康检查为准。
