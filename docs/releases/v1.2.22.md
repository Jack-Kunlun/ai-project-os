# v1.2.22 — 供应商连接测试失败原因

新增供应商时，连接测试未通过会在弹窗底部显示具体失败原因、处理建议和安全错误码。测试额度未生效或不足时提供“调整测试额度”入口，使用新页面打开以保留当前填写的连接信息。

覆盖配置校验失败、凭据无效、供应商限流或配额不足、模型请求被拒绝、超时、响应异常、能力不支持、部分模型测试未发出和结果待核对等情况。未知错误和网络异常显示明确的失败提示，不回显供应商原始错误、密钥或内部异常。接口返回缺少有效测试证明时不能保存；修改配置后清除旧测试结果。测试及保存期间锁定配置输入，避免旧请求返回后将旧配置误显示为测试通过；测试证明变化或过期时提示重新测试。

中英文文案同步，失败提示通过可访问的警报区域展示，长错误码可在窄屏换行。本次没有数据库迁移，也不调整测试额度、供应商配置、模型调用或凭据存储规则。

本地完成 29 个定向测试、相关 Lint、类型检查及隔离浏览器模拟验证；正式 PostgreSQL 浏览器门禁和发布镜像验证以本版本精确提交的主分支 CI 为准。未进行真实供应商、短信或支付调用。
