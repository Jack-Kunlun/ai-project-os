# v1.2.3 — 弹窗辅助入口与图标对齐修正

弹窗和抽屉中的智能问答改为底部左侧的次级辅助操作；普通页面保留既有悬浮入口，弹窗标题栏只保留标题和关闭。打开、关闭问答后保留业务表单草稿及焦点，发送授权和服务端校验保持原有流程。

页面主内容按原型统一为 1500px 最大宽度和同一套响应式边距；返回入口恢复为轻量文字链接。窄屏展开的最近会话使用顶部面板，收起后保留最小侧栏，避免挤压英文聊天区。

共享 SVG 按图标实际尺寸和当前字体统一内联基线；带文字的控件采用统一光学对齐，独立图标按钮保留居中。新建会话使用固定控件行高和独立文字项。

浏览器验收检查实际文字区域与 SVG 的中心差和重叠情况，覆盖全部页面、兼容路由、中英文桌面和窄屏，并附弹窗入口与会话按钮截图。

本次只有客户端界面、样式及验收变更，不新增依赖、数据库迁移或外部服务能力，迁移清单仍为 150 条。实际通过证据以精确提交 CI 为准，生产状态以标准发布回执和公网健康为准；不代表真实外部模型、短信、Git、OIDC 或 MCP 的新增现场联调。
