# v1.2.27 — 修复账号入口、通知、项目选择与后台额度问题

- 登录、注册、找回和换绑页面可粘贴带 +86、空格或分隔符的大陆手机号。受邀用户完成注册后回到原邀请，由本人确认接受；从公开帮助或联系页进入完整指南的用户可在登录后继续阅读。
- 帮助、联系、隐私和条款页的浏览器标签随中英文切换。
- 通知中心首页有更多历史记录时也会刷新。翻到历史记录或再次点击已选筛选时，当前列表得以保留。
- 项目计划按日历日期显示目标日，支持查找并关联较早的证据。个人知识可选择后续页的活跃和归档项目；工作区切换器支持访问首批结果之外的工作区。
- 后台用户和额度列表以当前搜索结果为准。额度补发预览按本地时间显示并提交默认到期时间。

用户指南已按当前策略说明上传字节上限和存储配额。

原始复现场景见[缺陷调查](../project/BUG-AUDIT-20261123.md)。此版本沿用当前数据库结构和发布流程。
