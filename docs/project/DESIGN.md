## 当前明确约定

| 对象 | 约定 |
| --- | --- |
| 视觉语言 | 沿用既有紧凑白灰蓝、字体、导航与主题；不重新引入旧式彩色嵌套卡片 |
| 弹窗与抽屉 | header/content/footer；标题仅出现一次；内容独立滚动，底栏为布局兄弟节点，不覆盖正文 |
| 操作区 | 问答辅助入口在左，主操作在右，同一底行；窄屏允许状态换行，但不挤掉必要操作 |
| 表单行为 | 保留原生 form 归属、required、回车提交、pending/disabled 和当次确认 |
| 上传与资料 | 文件与文件夹为同组选取；逐项反馈；保存原文件与识别分别表达；格式/容量说明默认展开可折叠 |
| 信息表达 | 不展示开发阶段编号或假能力；示例、模拟结果仅存在原型/隔离验收 |

## 复发问题开工检查

设计新页面、复用组件或调整原型之前，先查 [L-001～L-007](LESSONS.md)，将适用条目和状态放进任务卡。图标/文字、列表列线、边距归属、垂直对齐和新旧样式在代表组件中先检查，再批量应用到页面。交付原型和实际应用分别留下匹配同一有效设计版本的证据；记录未执行项。

具体缺陷的根因和修复结果写回对应任务并从 LESSONS 记录关联；规则修订更新本设计基线，不能只改一张截图或仅在聊天中承诺“记住”。

## 对齐验收必须具体化

- 表头和单元格按列用途与原型定义同一水平对齐；不能一律居中，也不能只验证 `vertical-align: middle`。
- 同行表单标签、输入框、选择器与按钮检查实际基线和高度；必填标记、帮助信息和错误信息不能造成无意错位。
- 模型表单的供应商选择与可输入模型字段共用 16px 下拉图标。图标垂直居中，距输入框末端 12px，输入文字预留 40px；点图标应打开对应选项。桌面和窄屏都检查实际边距与点击位置。
- 图标与单行/多行文字分别检查；不能因为检查器跳过多行就认为已通过。
- 长名称、长错误、英文、数字、空值及换行有明确排布；按钮文案完整且操作不被遮挡。
- 新版具体尺寸优先沿用有效原型与公共变量。尺寸未明确的项目在 T-004 记录判断及依据，不自行宣称已有统一数值。

## 实现与验收方式

2026-11-15 / C-015：全系统整改采用 [当前执行合同](UI-REMEDIATION-20261115.md) 的明确尺寸：独立面板/普通操作按钮/居中弹窗 6px、输入框 4px、贴边抽屉 0；业务操作最小高度 40px，窄屏字段 44px；弹层 header/content/footer 左右留白 24px、窄屏 20px。头像、状态圆点、图谱及认证品牌装饰按用途保留。颜色使用浅深主题语义变量；填充与可读文字分别定义。该合同替代靠旧 Tailwind utility 选择器猜测对象和改写几何的兼容方案，不改变权限、表单和业务状态机。

页面标题为桌面 25px、窄屏 22px；弹层标题为 16px。普通按钮与多行导航卡片使用不同原语，卡片保留自己的纵向内容结构。语义面板明确使用状态变体，不能被中性底色覆盖。嵌入式确认卡保留危险或外发警告色，不套独立弹层外壳。能力目录中的动作留在所属卡片内；单项编辑/确认的终结操作使用固定底栏。错误信息位于所属滚动区域内，短重试操作不得收缩为竖排，个人资料字段不随相邻说明拉伸。知识编辑器底栏的紧凑校验提示为 12px/1.7。嵌套保存后若旧触发器被重建，焦点回到仍存在的父对话框，保留后续键盘关闭与 Tab 导航。

1. 用 [UI 范围清单](UI-INVENTORY.md) 定义页面及状态；每项关联基准、任务和证据。
2. 先核对公共组件，再迁移使用方。C7 已退出旧 utility 兼容覆盖，使用方显式使用公共语义类；后续清理仍需检查使用方及实际渲染，不盲删类名。
3. 同一控件避免各页面独立定义外观；必要差异显式为变体。迁移同时检查主题、语言、窄屏和交互状态。
4. 候选截图使用固定数据和环境，真正查看并记录偏差。确认正确后才建立回归基准；不能自动接受截图差异来消除失败。
5. 全站改版覆盖全部适用入口与操作状态；局部修改只检查受影响范围及共享组件调用方。截图差异、几何断言和人工视觉审阅互补。
