# v0.7.17 — Git 已验证地址持久化

## 更新内容

连接测试保存成功 `ls-remote` 实际使用的已验证 IP 集合和网络指纹。后续手动及自动代码读取使用该集合，执行前校验地址、网络策略和指纹，保留原主机名的 TLS／SSH 校验、授权快照和每次 Git 调用前的租约检查。新 DNS 地址必须经过显式重测。

HTTPS 固定地址项在 Git 进程内不再使用会过期的临时条目，禁用重定向的规则保留。旧连接没有地址集合时继续执行原有严格 DNS 校验，显式重测后才启用持久化地址。配置和凭据安全变更会清除相关验证状态。

新增迁移 `20261007010000_persist_verified_git_addresses`，迁移链从 140 条变为 141 条；只新增内部验证字段和相关数据库约束，不增加部署服务。
