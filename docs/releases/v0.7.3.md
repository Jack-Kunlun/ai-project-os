# AI Project OS v0.7.3

本补丁修复标签 CI 跳过完整数据库作业的问题：每个发布标签都强制运行源码覆盖率、完整 PostgreSQL 门禁、浏览器与无障碍检查、性能预算及隔离版构建，并核对同一提交的主分支 CI。生产发布以标签 CI 中实际成功的数据库作业为门槛。产品功能与 [v0.7.0](v0.7.0.md) 相同，停写备份合同修复沿用 [v0.7.2](v0.7.2.md) 的源码。

2026-10-05 按权利人授权更正作者历史，并删除 `v0.6.0-dev.9` 至 `v0.6.0-dev.14`、`v0.7.0` 至 `v0.7.3` 共 10 个受影响标签；不重建这些标签。GitHub Release `v0.7.0`、`v0.7.1`、`v0.7.3` 转为草稿。因此当前不能再从这些旧标签取得安装来源；下一次发布需使用新版本、新标签，另行校验生产来源与已更正历史的部署契约。本文保留 `v0.7.3` 的版本及部署记录，不代表其旧标签仍存在。
