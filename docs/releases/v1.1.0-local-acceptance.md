# v1.1.0 — 平台体验与智能问答重构 开发版

v1.1.0 按已确认的高保真原型重做平台体验，统一问答会话和知识浏览入口。用户侧先完成本地验收，随后完成管理平台；最终集成候选已通过本地验收，当前未提交或发布。范围和证据见[用户侧计划](../prototype-user-platform-plan.json)和[管理平台计划](../prototype-admin-platform-plan.json)。

用户侧采用常驻侧栏，保留工作台、智能问答、我的项目、我的知识四个全局入口。当前项目支持切换，项目计划、项目资料、项目概览、简报与调查、项目自动化、项目管理直接显示，切换项目后栏目与页面内容同步切换。页面采用白灰蓝配色、紧凑标题与列表；新增、编辑和执行继续使用明确的操作入口。

智能问答统一选择全量可访问内容、个人空间或单个项目。同一会话可以逐轮切换范围；每轮保存完整问题、回答、当时范围、模型与引用快照，重新打开后可继续追问。确认弹窗展示实际外发资料、完整历史上下文和预计平台额度，发送前重新核对账户、项目、来源版本与模型路由。历史会话只对本人可见；撤销相关项目访问后，会话标题、搜索结果和正文一并停止展示。

项目降为只读或归档后，已有历史仍可查看，包含该项目的旧问答不能继续外发给模型。模型结果未知时保留预留额度与审计证据，并阻止同一会话头上的再次发送，避免重复调用。

本次统一问答采用有界的关键词资料匹配，使用平台默认生成模型。完整历史超过上下文预算时要求新建会话；不静默裁剪历史，也不把关键词匹配显示为语义检索。原有个人与项目的语义索引、资料识别和维护能力保留。个人知识的旧审计记录没有保存问答正文，不生成虚构的历史会话。

我的知识提供全部知识、通用记忆和知识图谱。图谱在可旋转的三维空间展示真实来源归属、已确认事实与已记录关系，支持拖动节点、平移、缩放、适应全图和重置布局。点击个人资料、项目资料或事实节点，直接打开对应的资料详情；位置调整只影响当前视图，不写入知识关系。较大范围分批展示。项目资料保留资料、整理结果、识别任务三个栏目，智能问答使用统一入口；识别与整理继续由后台队列处理，原有逐次确认和任务取消边界保留。

管理平台采用平台总览、用户与权益、配置中心、安全中心、运维中心五个直接入口，组内使用横向栏目，保留原有管理操作和逐次确认。平台统计包含统一问答及能由平台预留记录证明的个人知识问答，排除个人 BYOK，仅返回数量、用量和安全分类。成功问答在追加轮次的同一事务保存真实用量；趋势按上海自然日归属，未知调用按终态待核对统计。未接入真实监控的原型资源示例不作为运行数据展示。

## 三维图谱补充验收

补充三维坐标与透视视图、节点拖动、旋转和平移、滚轮和按钮缩放、适应全图、重置布局与键盘操作。密集场景使用圆点节点，范围显示标签，资料和事实在悬停、聚焦或选中时显示标题。点击个人知识打开其详情；点击项目资料或事实打开实际来源详情。节点拖动不触发跳转，位置调整不写入资料关系。

此次只改动四个图谱客户端或纯布局文件，不修改 API、权限、额度或 Schema。最终源码默认覆盖率检查 1,428 通过，171 项 PostgreSQL 用例按默认开关跳过；行 61.55%、分支 79.37%、函数 67.77%。构建、lint、类型检查及原性能预算通过；图谱路由 184.8/185 KiB，全站静态客户端库存 830.4/850 KiB。完整浏览器运行其余 18 项通过；图谱修正后使用最终镜像单独复验通过，覆盖真实来源、桌面和手机、键盘及 WCAG。
