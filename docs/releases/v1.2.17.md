# v1.2.17 — 看板滚动与问答留白

项目计划看板在工作项较多时会把整个页面撑长。各列任务区域现在独立滚动，高度最多容纳五张卡片，并随短屏收缩；列标题、任务数量和添加入口保持在滚动区域之外。

智能问答的引用列表与 Token 消耗卡片之间恢复 12px 间距，悬浮问答与独立问答页共用该布局。看板、问答内容及最近会话列表使用细滚动条、透明轨道，悬停或键盘操作时加深；高对比度模式保留系统滚动条。

发布验证覆盖较多任务、少量及空任务列、五张卡片高度上限、列内滚动、窄屏内容、问答引用与用量卡片间距，以及滚动条状态。正式发布复用精确同 SHA 的成功主分支 CI 和不可变镜像，部署后核对生产版本、健康状态及实际页面。

无业务逻辑、API、依赖、Schema 或迁移变化，迁移清单仍为 150 条。正式上线结果以发布回执和生产验证为准。
