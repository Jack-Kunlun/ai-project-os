## 如何理解“已完成”

| 层次 | 本次如何记录 |
| --- | --- |
| 已实现 | 当前版本有相应实现入口和产品/版本记录；不等于本轮所有业务场景通过 |
| 历史已验收 | 原记录明确写出候选、环境、场景和结果；只在原范围内引用 |
| 历史已发布 | 有精确版本、提交和成功发布回执；仅有版本说明不能证明上线 |
| 当前重新验收 | 本轮实际执行并留下结果；2026-11-02 为文档盘点；2026-11-15 C7 完成下述 UI 范围本地验收，未验证线上与真实外部服务 |
