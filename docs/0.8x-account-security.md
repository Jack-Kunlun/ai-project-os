# 0.8.x 账号恢复与手机号管理

实现基线：v0.7.17 / `5cf2c74b3554e8c5c1b85f47f056ed0c02b50743`；发布时已整合 v0.7.18 / `c8e341f39fbb77b44bc8a8f2a8483c3bd5ac2bd5`。首个开发版本：`0.8.0-dev.1`。实现和本地验收记录如下；提交、远程 CI、标签与生产状态分别记录于[版本说明](releases/v0.8.0-dev.1.md)。

## 首批范围

| 入口 | 行为 | 身份证明 |
| --- | --- | --- |
| 登录页 → 忘记账号或密码 | 返回原登录名并重设本地密码，完成后重新登录 | 已绑定手机号的专用恢复验证码 |
| 个人中心 / 管理员账户 → 绑定手机号 | 为原账号增加登录和恢复号码，保持账号与工作区 | 当前登录密码及新手机号验证码 |
| 个人中心 / 管理员账户 → 更换手机号 | 从原号码换至新号码，保持账号与工作区 | 原号码及新号码各自的专用验证码 |

沿用 +86、每次发送前图形验证码、短信服务商配置和持久化发送/验证预算。找回流程不依赖开放注册，不会创建新账号；短信发送阶段不公开号码对应账号是否存在。所有证明必须单次消费、短期有效并绑定用途。手机号不可占用其他账号的号码，也不能隐式合并其他身份。

首次绑定需要本地密码。仅使用 GitHub、OIDC 或短信登录且尚无密码的用户，先在原账号设置本地密码并重新登录，再绑定号码。换绑完成后，原号码不再作为该账号的手机号登录别名；若登录名本身就是原手机号，需先显式修改登录名，再换绑。账号关闭后原号码的既有释放规则继续保留。

## 安全与兼容

验证码应绑定发送当时的账号和安全版本。恢复、绑定和换绑在数据库事务中重新检查有效账号、当前号码、用途、配置版本、有效期和证明归属；原子完成证明消费、变更、会话撤销与安全审计。安全版本变化应拒绝旧会话、旧验证码和旧请求。

历史迁移不修改；通过新迁移扩展手机号更新的数据库校验，保留注册、号码别名和不可逆注销保护。数据库拒绝无有效证明/审计的直接手机号更新。审计不保存密码、验证码或完整手机号。

不在本批实现：邮箱密码找回、国际号码、短信 MFA、原号码不可用的自助换绑、人工申诉后台、管理员代改手机号、解绑、账号合并或第三方身份迁移。上述能力不在产品界面宣称可用。

## 有界执行与验收

1. 安全服务和新迁移：观察结果为已绑定号码可恢复原账号，绑定/换绑只改变原账号；定向真实 PostgreSQL 测试覆盖重放、并发、配置与账号版本漂移、会话失效和数据库绕过。最多两轮基于新证据的修复；重大合同未知时停止相关实现。
2. 页面和接口：观察结果为登录找回入口和两类账户管理入口可访问，缺失证明无法提交，号码脱敏，短信不可用时明确提示；检查同源拒绝、输入限制以及桌面/手机布局。复用既有短信与图形验证码组件，不重构认证架构或无关页面。
3. 整合：运行新旧认证定向测试、一次类型检查、受影响文件 ESLint、Prisma 生成/迁移校验、一次生产构建和一次独立安全审查。仅在定向失败、审查缺陷或扩大影响面的证据出现时增加检查。

真实短信送达与三种供应商的生产配置、浏览器完整认证操作、远程 CI、完整发布门禁及生产部署分别验收。隔离数据库中的供应商替身只证明本地状态机和数据约束。

协议与恢复边界参考：[OWASP Forgot Password Cheat Sheet](https://cheatsheetseries.owasp.org/cheatsheets/Forgot_Password_Cheat_Sheet.html)、[OWASP Authentication Cheat Sheet](https://cheatsheetseries.owasp.org/cheatsheets/Authentication_Cheat_Sheet.html)。
