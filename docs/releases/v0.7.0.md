# AI Project OS v0.7.0

生产工具首次安装时发现本网关捕获组契约检查错误，安装器在替换系统工具前失败关闭；生产未升级。[v0.7.1 补丁](v0.7.1.md)修复了安装入口，但生产升级又在备份标签校验处失败。后续使用 [v0.7.3 补丁](v0.7.3.md)，历史标签保持不变。

本版源码包含用户名密码注册与 GitHub 首次登录建号、个人 Git 自动同步、受控外部 MCP 读取、对外只读 MCP、跨项目检索、Office 图片人工审核、显式 OIDC 身份绑定，以及经人工审核的网页来源。S1b 的 JavaScript 页面可进入审核发布链；同源站点表单登录结果仅供项目 Owner 私有预览或丢弃，不能进入项目通用来源、搜索、AI 或对外 MCP。商业自助购买不在本版范围。

## 本次发布的现场验收豁免

发布决策明确豁免以下尚未具备的现场条件：专用 Linux 浏览器 broker 主机、获授权的真实站点、真实外部服务，以及两个外部 MCP 客户端。因此本版只证明相关代码和隔离环境门禁，不声称生产中的认证网页抓取、外部 MCP 互操作或真实 Git/OIDC 服务已经通过现场验收。首次启用前，部署方须分别完成目标服务的权限、凭据、网络与安全验收；保持未验收能力的生产开关关闭。S1b 在缺少独立 broker 和授权站点时不可用。

## 发布与生产升级

稳定版标签必须是主分支同一提交上的带注释 `v0.7.0`，且主分支完整数据库 CI 与标签 CI 均成功。GitHub Release 可在这些条件满足后发布；它不证明生产已升级。

生产首次升级仍须依照 [生产部署](../production-deployment.md) 的专用 0.7 通道：可信运维先在现有主机安装精确标签的受限工具，再通过 Actions 停写、验证异地备份、核对迁移账本、执行 117→135 迁移并复核公网 app/worker 健康。任何一步缺失或失败都不得把生产标记为 `0.7.0`。生产实际版本以公网 `/api/health` 为准。
