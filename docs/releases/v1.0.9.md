# v1.0.9 — 页面操作分离与证据驱动事实整理

查看页面聚焦数据、搜索和筛选，项目、个人空间和管理后台中的新增、编辑、配置与执行通过明确入口打开对话框、抽屉或专用操作流程。操作区支持取消、失败保留输入、键盘操作与关闭后的焦点返回；资料核对仍有独立入口。

导入项目文件或手工资料后，可以在当前导入流程确认本次模型及资料范围并继续整理，无需再次挑选资料或逐条确认符合条件的抽取结果。长文件按有界分段整理，保留来源与摘录，重复执行不会覆盖已有事实。

自动形成事实只适用于项目上传文件、已核对图文和手工资料：正文必须是来源摘录中的逐字连续内容，来源内容保持一致，无未决措辞且无明确既有事实冲突。系统沿审核状态机保存准入原因和追加式确认历史，不记为人工确认。这里的事实表示有原文依据的项目记录，不表示已独立核实真实世界的真实性。

改写、冲突、不确定、示例或代码内容保留待处理；网页、仓库和 MCP/动作结果仍需人工核对。图片、扫描件和 Office 内嵌图片仍须先核对识别文字；模型外发仍需确认本次资料范围，语义索引更新保持独立确认。既有事实不自动覆盖，历史待处理内容不因升级而批量自动确认。

本版本同步 1.0.8 的发布修复，使用主分支 CI 构建并验证的不可变摘要镜像。相对 1.0.8 无新增数据库迁移，完整清单仍为 146 条；迁移清单相同时，正式发布跳过迁移和权限协调。常规发布沿用现有不执行备份/恢复流程及健康验收后清理旧镜像、闲置构建缓存的策略。

本说明记录源码候选。发布前须取得最终提交的成功主分支 CI；正式发布仍由用户在「发布正式版本」选择 `main` 手动发起。CI 与本地隔离模型响应只证明确定性行为，真实模型、Git、OIDC、第三方 MCP 的现场结果须单独记录。生产完成以精确提交的发布回执及公网健康为准。
