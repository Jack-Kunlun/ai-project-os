# v1.2.25 — 修复 OpenAI 私有代理访问与连接超时

UFW 默认拒绝入站连接时，应用容器可能无法访问宿主机的私有代理端口。生产安装器现在校验项目 Docker 网桥、私有子网及网关，按需创建只允许该网桥访问代理 TCP 17890 端口的 UFW 规则，并在修改应用配置前验证 Worker 可以连接。已有规则冲突时停止；回滚只处理本次安装拥有且仍匹配的规则，保留其他规则和默认策略。

OpenAI 请求的取消和超时现在覆盖 CONNECT 隧道建立之前的阶段，同时关闭尚未进入连接池的代理 socket，避免测试长时间等待。保持固定官方接口、TLS 校验、代理鉴权、OpenAI 域名限制及禁止回退直连。

本次没有数据库迁移，不修改供应商密钥或模型测试额度。发布应用代码不代表已启用代理，仍需完成受控安装和现场网络验收；真实 API 密钥由供应商连接测试另行验证。
