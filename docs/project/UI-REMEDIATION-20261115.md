## 实际验收场景与边界

- 全入口：既有 ui-consistency-matrix 发现 77 个 page.tsx，访问 7 种语言/主题/宽度配置；新增对最终 DOM 的公共按钮颜色/圆角/高度断言。开启 MCP 页面功能以实际验收入口，不用 404 替代。
- 异常与弹层：ui-style-states 对非公共、非重定向页面的实际浏览器 GET 读请求施加等待和 503，记录请求集合、实际文字、截图和无横溢结果；无入口客户端读请求单列，不伪造服务端失败。英文浅色桌面与中文深色窄屏补齐组合。随后以真实读取结果逐一打开可见 OperationPanel 并取消，不调用外部服务或提交写操作。
- 同类操作：既有全部 browser 套件覆盖资料/上传/长文本/问答/配置/确认/权限/校验/pending/focus；新增管理端嵌套危险确认框的圆角、留白、名称校验、取消及焦点恢复断言。已有弹层检查增加最终样式合同。
- 原缺陷：T-032 对开启状态的 MCP 动作入口运行实际 color-contrast；T-033 检查 portal 后的真实按钮背景；T-034 检查管理端抽屉里的确认框与用户侧共享实现。断言通过仍需实际查看截图。
- 环境：本机源码生产构建、隔离 pgvector PostgreSQL 与独立主密钥/上传目录；迁移及角色权限使用仓库现有引导逻辑。此环境只证明本地候选，不替代正式 CI 同镜像或线上验收。
