# AI Project OS v0.7.1

生产升级在停写后的备份入口以 `BACKUP_TARGET_TAG_INVALID` 失败。迁移未开始，旧版 `0.6.0-dev.14` 已恢复健康；该标签保留作历史记录，后续使用 [v0.7.3 补丁](v0.7.3.md)。

本补丁修复 0.7 首次生产工具安装器对受限网关捕获组的错误检查，并将安装、网关、迁移部署器和工作流固定到精确的 `v0.7.1` 标签。产品功能与 [v0.7.0](v0.7.0.md) 相同；四项现场验收豁免继续适用，未验收能力在生产中保持关闭。

## 发布与生产升级

`v0.7.0` 的首次工具安装在替换系统工具之前以 `RELEASE_TOOLING_V07_GATEWAY_CONTRACT_INVALID` 失败；该标签不能改写或用于重试安装。仅从通过主分支完整数据库 CI 和精确标签 CI 的带注释 `v0.7.1` 标签取得安装器。安装前保存现有工具和主机状态，并按[生产部署](../production-deployment.md)完成隔离主机演练。

工具安装成功并返回 `TOOLING_V07_READY` 后，才从 `main` 手动运行 **Deploy v0.7 with database migration**。工作流核对当前运行源版本、117→135 迁移、停写异地备份和公网健康。GitHub Release 不代表生产已升级；生产版本以公网 `/api/health` 为准。
