V5.1.2 是 V5.1.1 的部署安全补丁，不新增数据库迁移、不扩大 Action Engine、MCP 或项目智能体权限，也不改变正式部署的数据模型。

## 部署安全修复

- 生产 Compose 现在把 `AI_PROJECT_OS_SECURE_COOKIES` 显式传递给应用容器，避免宿主机 `.env` 已启用安全 Cookie、但应用容器仍使用默认值的配置断点。
- 正式 HTTPS 部署必须在 `.env` 中使用精确的小写值 `AI_PROJECT_OS_SECURE_COOKIES=true`；未设置时仍保持本地 HTTP 开发所需的默认值 `false`。
- 回归测试固定该变量只出现在 `app` 服务的环境配置中，并核对示例环境与 README 均保留部署说明。
