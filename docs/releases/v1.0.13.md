# v1.0.13 — 个人默认模型与项目资料后台任务

个人知识库直接提问默认采用平台已验证的生成模型并使用平台额度，无需另建个人连接；已验证的个人 BYOK 仍可选。发送前展示本篇范围、模型与费用承担，确认绑定文档版本、问题、证据和路由配置，回答只能引用本次证据。

项目资料固定为“资料、整理结果、问项目、识别任务”栏目，页头保持稳定。切换栏目不会打开添加窗口；只有显式点击“添加资料”才进入录入。整理与核对集中在资料内，提问时需要准备资料会在同页完成范围确认，不再要求用户寻找索引维护页。

图片识别和自动整理在确认后排队，由 Worker 按持久化授权执行。用户可以继续操作其它文件，并在识别任务查看状态、进度、结果和允许的取消操作。实际模型并发限制保持，排队不占执行名额，队列总量有界；已发送或未知的外部请求不会被伪报为取消或自动重发。权限、资料、模型或授权过期变化都在外发前重新核验。

本版本追加个人问答平台计费来源绑定迁移，数据库清单为 147 条。新字段可空，既有项目、个人语义、个人视觉计费分支及数据保留；新增问答来源受数据库约束与审计校验。成功调用按实际 Token 结算，未知外发保留待核对预留，未派发才释放。迁移发布须通过完整 PostgreSQL、身份和 OID10 门禁；迁移启动后的失败按维护恢复流程处理，不承诺自动回滚。

正式发布复用精确主分支 CI 的同一不可变镜像，并分别记录生产迁移账本、版本健康和真实模型使用验收。
