# AI Project OS V5.0.0 发布说明

发布日期：2026-08-30

V5.0.0 在长期记忆和证据驱动项目运营之上增加时态项目世界模型。系统不再只展示彼此独立的已确认条目，而是把当前有效事实、人工关系、替代链、开放冲突和项目计划健康度合成为一份确定性、可复现、可固化的项目状态。Dashboard、项目简报和只读智能体读取同一状态与输入指纹；AI 不能确认事实、建立关系、替代事实或覆盖系统状态。

## 发布能力

- 项目导航增加独立“项目状态”页面，集中展示当前状态、事实、证据修订、关系、冲突、计划健康、状态快照和治理审计。
- 当前状态只纳入已经人工确认、来源活动、已生效、未过期且未被替代的事实。
- 状态由本地规则确定性计算为“运行正常”“需要关注”“存在风险”或“资料不足”，不会调用模型。
- 支持“支持、冲突、依赖、阻断、由此导致、解决、相关”七种事实关系。每条关系固定双方精确修订、依据、操作者和 SHA-256 指纹。
- 支持同类型事实建立单一替代链。旧事实转为只读历史，新事实记录前任，双方追加独立修订。
- 支持固化不可变项目状态快照；输入没有变化时保持幂等，不创建重复快照。
- Dashboard 增加跨项目世界状态提醒，并把存在风险的项目作为推荐下一步。
- 项目简报和只读智能体把确定性状态、当前事实、关系、计划健康与状态指纹纳入项目概览；生成简报的状态字段由系统状态固定。

## 时态与证据边界

- 事实关系只能连接同项目、当前已确认事实，且必须绑定端点的最新修订。事实发生修订、过期、来源退役或被替代后，旧关系会标记为陈旧，不会静默迁移。
- “冲突”关系由用户明确建立；记忆质量检查发现的开放冲突作为独立确定性信号进入状态。系统不会自动判定哪条事实正确。
- 替代关系拒绝跨类型、重复后继、分叉、过期页面提交和循环链。被替代事实保留原确认时间、来源、证据和完整历史。
- AI 候选事实被替代后仍保持原 AI 来源和人工确认链；替代改变当前有效性，不抹去来源证明。
- 关系退役、事实替代、状态固化均进入追加式审计。关系只能一次性退役；快照和审计不能更新或删除。
- Viewer 保持只读；Editor 或 Owner 才能建立/退役关系、建立替代链和固化状态。

## 与既有能力的关系

- “资料与条目”中的 Project Snapshot 继续作为已确认条目的兼容读取点；V5 状态快照额外包含生命周期、关系、冲突和计划健康度。
- 项目世界模型不会自动创建事实或关系，也不会自动解决冲突、重建语义索引或生成执行动作。
- 项目计划、Action Engine、MCP 和智能体权限边界保持不变。系统仍不提供模型驱动的代码修改、Git 写入、Shell、分支/PR、合并或部署能力。
- 外部模型、Git、OIDC 与 MCP 是否可用仍取决于用户在页面配置的真实服务和凭据；本地发布不代表这些第三方连接已经逐一验证。

## 升级说明

升级前必须同时备份 PostgreSQL、`ai-project-os-secrets` 和 `ai-project-os-uploads`，并保证来自同一备份窗口。不要执行 `docker compose down -v`。

V5.0.0 的第 48 个迁移会：

- 新增事实关系、项目状态快照和世界模型审计表，以及关系类型和审计事件枚举。
- 为关系端点增加同项目与精确修订外键，并增加当前修订、确认状态、对称关系顺序和一次性退役门禁。
- 为事实替代链增加唯一后继、同类型、确认状态和无环约束。
- 扩展事实修订动作，并允许“已被替代”修订继续保留确认时间和 AI 候选来源一致性。
- 为状态快照和治理审计增加数据库级不可变保护。

已有事实不会被自动建立关系或替代链，升级后状态由现有确认状态、来源生命周期、有效期、质量问题和项目计划直接计算。用户可以进入“项目状态”核对结果，再按实际业务建立关系和固化快照。

```bash
git switch main
git pull --ff-only
docker compose config --quiet
docker compose up -d --build
docker compose ps --all
curl --fail http://127.0.0.1:3000/api/health
```

完整使用方式见[操作手册](../operation-manual.md)和页面“使用指南”。
