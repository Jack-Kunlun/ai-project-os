# v1.0.7 — 兼容 GitHub 新版发布令牌

修复正式发布器拒绝 GitHub 新版 Actions 安装令牌的问题。令牌按不透明凭据传递，不解码或依赖 JWT 内容；仅检查传输大小、HTTP Bearer 安全字符和精确 CI 运行标识。凭据仍通过加密 SSH 标准输入传递，不进入命令参数或日志；镜像拉取使用 root 私有临时 Docker 配置，完成后删除。

本仓库主分支推送的 CI 在构建前使用本次真实 Workflow 凭据经过同一 JSON 生产者和发布器解析器完成只读预检，成功仅输出固定标记；格式异常会在构建前停止，不输出凭据或异常正文。PR 与其他分支不运行真实凭据预检，继续使用合成凭据回归测试。

`v1.0.6` 的正式发布在读取凭据时失败，尚未拉取目标镜像、切换应用或执行镜像/缓存清理；其不可变标签保留。永久发布工具已在该次 Workflow 中成功更新并核验，后续工具更新无需重复手动安装。

本版本继承 [v1.0.6 的 CI 镜像复用与发布精简](v1.0.6.md)，以及缓存统计对 Buildx SI 单位的兼容。正式发布仍由用户手动点击，成功验收后清理过期应用镜像和闲置构建缓存。不新增数据库迁移；实际上线版本与释放空间以公网健康和本次发布回执为准。
