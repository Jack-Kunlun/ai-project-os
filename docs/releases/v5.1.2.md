# AI Project OS V5.1.2 发布说明

发布日期：待定

状态：发布候选（等待精确候选提交的远端 CI）

V5.1.2 是 V5.1.1 的部署安全补丁，不新增数据库迁移、不扩大 Action Engine、MCP 或项目智能体权限，也不改变正式部署的数据模型。

## 部署安全修复

- 生产 Compose 现在把 `AI_PROJECT_OS_SECURE_COOKIES` 显式传递给应用容器，避免宿主机 `.env` 已启用安全 Cookie、但应用容器仍使用默认值的配置断点。
- 正式 HTTPS 部署必须在 `.env` 中使用精确的小写值 `AI_PROJECT_OS_SECURE_COOKIES=true`；未设置时仍保持本地 HTTP 开发所需的默认值 `false`。
- 回归测试固定该变量只出现在 `app` 服务的环境配置中，并核对示例环境与 README 均保留部署说明。

## 验收状态

- 安全 Cookie 功能提交 `93512c1` 已通过 Compose 隔离测试、配置渲染和差异检查；渲染结果确认显式值为 `true`，未设置时为 `false`。
- 精确 V5.1.2 候选提交仍需通过 Prisma/迁移、Lint、类型检查、覆盖率、PostgreSQL 门禁、生产浏览器/WCAG、性能预算和隔离本地 Compose 候选门禁。
- GitHub Actions、正式标签和生产服务器部署是后续独立发布步骤；本文档不声明线上实例已经升级。

## 升级说明

从 V5.1.1 升级不新增 Prisma 迁移。部署前仍应备份 PostgreSQL、secrets 和 uploads，在生产 `.env` 设置 `AI_PROJECT_OS_SECURE_COOKIES=true`，随后核对 `/api/health`、Worker 心跳、版本 `5.1.2`、重启持久性，以及登录响应实际下发带 `Secure` 属性的会话 Cookie。本地候选流程不会修改或重启正式实例。
