# AI Project OS v0.7.2

本补丁修复 0.7 首次生产升级的备份目标标签合同：备份程序、归档校验器和恢复程序均接受 `v0.7.2` 的停写备份名称；安装器在替换生产工具前核对这些合同。受限网关、部署器、预检、工作流及源码版本均固定到同一精确标签。产品功能与 [v0.7.0](v0.7.0.md) 相同。

`v0.7.1` 的工具安装成功，但生产升级在停写后的备份入口以 `BACKUP_TARGET_TAG_INVALID` 失败。没有创建该次停写异地备份，也没有执行数据库迁移；旧版 `0.6.0-dev.14` 已恢复健康。不要改写既有标签。

生产升级从通过完整数据库主分支 CI 和精确标签 CI 的带注释 `v0.7.2` 标签取得安装器。现有 `v0.7.1` 网关无法自助安装新标签，须由可信主机运维在 root 会话中先保存主机与工具状态，再直装并核对 `v0.7.2` 工具；本次经用户明确决定跳过隔离主机演练。`tooling-v07-status` 返回 `TOOLING_V07_READY` 及精确标签和提交后，从 `main` 手动运行 **Deploy v0.7 with database migration**。工作流必须验证停写异地备份、117→135 迁移和公网应用及 Worker 健康；GitHub Release 不代表生产已升级。

本次发布继续豁免专用 Linux broker 主机、授权真实站点、真实外部服务和两个 MCP 客户端的现场验收；未验收能力在生产中保持关闭。
