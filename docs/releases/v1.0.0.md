# v1.0.0 — 非计费正式版

本版本将已部署并完成所选现场验收的 `v0.8.0-dev.4` 候选收口为 `1.0.0`。正式版差异仅包含版本标识、对应版本断言、README 与本文；应用逻辑、依赖锁文件、部署工具和数据库迁移不变。源码版本、精确标签 CI 和实际生产版本是独立证据，线上状态以 `/api/health` 与发布回执为准。

邮箱注册后可使用已验证邮箱与密码登录。修改密码需要当前密码与当前邮箱的验证码；已验证邮箱不能从个人资料修改或移除。邮箱换绑与邮箱找回不属于此版本，详见[邮箱认证配置](../email-authentication.md)。

候选同时修复短信代理 HTML 429 的提示与冷却，以及 Office 图片识别成功后被空白旧草稿遮盖的问题。实际修复版本为 `v0.8.0-dev.4`，正式版继承相同实现。

## 保留限制与明确豁免

- 收费与支付不在本轮范围；真实第三方 MCP、两个客户端互操作、OIDC 登录/绑定，以及独立 Linux 浏览器 broker 仍待单独配置和验收。代码或隔离测试通过不代表这些外部能力已现场可用。
- 按用户已确认的快速发布范围，本轮不新增备份、恢复演练和旧数据验收。这些是豁免，不能表述为通过；生产身份、迁移账本、健康和既有数据保留门禁继续执行。
- Next.js 16.3.8 及兼容传递依赖修复已包含在候选。`deepmerge-ts 7.1.5` 的 **high** 风险仍限于受信任 Prisma CLI 配置/构建/迁移路径，复评到期日 **2026-10-27**；本版不升级 Prisma major、不覆盖该依赖 major，不宣称漏洞清零。见[依赖安全例外](../security-dependency-exceptions.md)。
- 合成资料项目已归档，可恢复，保留审计证据；受控 Git 测试分支保留作为证据，不会继续自动读取。邮箱测试账号已通过正常产品注销，未做数据库历史硬删除。
